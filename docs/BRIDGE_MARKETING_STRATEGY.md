# 브릿지브랜드 마케팅 전략기획

## 분석 보고서 표준

2026-10-20 작성한 `BRIDGE 브랜드평판지수 이해와 비교 설명` 문서의 설명 구조, 표, 용어, 해석 방식을 일반 분석서의 표준으로 사용한다. 대상별 결과는 공개 근거 범위와 신뢰등급을 함께 해석하며 내부 가중치, 비밀키, 임계값은 외부 보고서에 노출하지 않는다.

- 기본 브리핑: 표준 분석서의 핵심 요약과 대상별 퍼블리시티 1편
- 일반 브리핑: 표준 분석서 전체 수준의 설명과 대상별 퍼블리시티 1편
- 스페셜 브리핑: 일반 브리핑에 표·그림·다이어그램, 변화 원인, 데이터 의미, 전문 해설을 확장하고 대상별 퍼블리시티 1편 추가

모든 단계는 단순 순위 설명이 아니라 BRIDGE 6축의 구조, 변화 방향, 활동량, 근거 상태, 해석 범위를 구분한다. 기존 공개 기사를 덮어쓰거나 동일 회차를 중복 발행하지 않는다.

## 1회성 및 확장 서비스

- BRIDGE SNAPSHOT: 1회 일반 브리핑
- BRIDGE DEEP DIVE: 1회 스페셜 브리핑
- BRIDGE GLOBAL EDITION: 번역·현지화 옵션. 초기에는 한국어·영어를 우선하고 일본어·중국어로 확장한다.

## 제작 원칙

최상위 일일 스페셜은 매일 장문의 동일 보고서를 반복하지 않는다. 월요일에는 직전 월~일을 아우르는 완전판 주간 스페셜을 제공하고, 화~일에는 새 사건·축 변화·근거 변화에 집중한 데일리 스페셜을 제공한다.
