## 3. 연구보고서 문체
각 해설 단위는 *문제가 되는 질문 → 확인된 값과 범위 → 해석 가능한 관계 → 대안 설명과 제한 → 다음 확인*으로 이어진다. 단순 서술량 확대 대신 **대상명·기준일·축 상태·수치와 비교조건**이 포함된 관측 기반 설명을 늘린다.

### 사실·해석·가설·실무 권고 분리
- 사실: “○○은 YYYY-MM-DD ○○ 분야 T100에서 DAILY NN.NN, N위로 관측됐습니다.”
- 제한 해석: “현재 동일 비교집합에서는 ○○ 축이 다른 유효 축보다 선명하게 관측됩니다. 다만 이는 대상의 모든 능력과 가치를 판단하는 지표가 아닙니다.”
- 검증 가설: “이 차이가 반복 접점의 변화와 연결되는지는 다음 회차의 독립된 자료로 검토할 질문입니다.”
- 실무 권고: “기관은 점수 상향 메시지보다 새 직접 근거가 확보되는 접점과 결과 기록의 일관성을 먼저 점검할 수 있습니다.”

### 문단 구조
한 문단의 권장 호흡은 3–5문장. 첫 문장은 해당 대상을 지정하고 핵심 판단을 설명한다. 가운데는 관측값·비교 범위·예외를 제시한다. 마지막은 다음 장의 분석 목적이나 실제 검증 질문을 열어 둔다. 모든 단락을 정형화하거나 숫자 없이 형용사만 반복하지 않는다.

### 피해야 할 연결과 자동 표현
- “따라서 ... 따라서 ... 결국 ...”을 연속 반복하지 않는다.
- “입체적/유기적/시사점/관계 구조”처럼 내용 없는 표제어를 피하고 **어느 축의 어떤 관측자료가 무엇을 설명하는지** 적는다.
- “하락했으므로 나빠졌다”, “활동량이 높아 긍정적”, “신뢰등급이 높아 평판이 높다”, “참조=50점”, “인과가 확인됐다”를 금지한다.
- 숫자와 직접 근거가 없으면 새 사건이나 이유를 지어내지 않는다. 동일 문장 반복으로 페이지 수를 채우지 않는다.

## 4. 시각자료 편집 계약
각 자료는 *독자의 질문 — 무엇을 관측했는가 — 보이는 차이 — 해석 제한*을 설명해야 한다.
1. 점수분포 도트 플롯: 순위 간격이 실제 점수 간격과 다름을 명확히 표시.
2. 6축 막대: 유효값과 참조값 시각적으로 구별; B→R→I→D→G→E 순서 유지.
3. 상태 리본: 6개 축의 관측·유지·참조 상태를 텍스트와 함께 제시. 색만으로 판별하지 않음.
4. 관계 경로 2단 지도: 왼쪽 B/R/I 오른쪽 D/G/E. 화살표는 설명 순서이고 인과 방향이 아님.
5. 3대상 비교 패널: MY PICK, COMPARE A, COMPARE B를 별도 톤으로 구분하되 가치 판단으로 오해되지 않게 표시.
6. 활동량 비교: P는 사건 움직임이고 DAILY는 관계 수준; 같은 막대 높이로 동일시하지 않음.
7. 전략·검증 카드: 당장 할 일과 근거 확보 후 판단할 일을 나눔.
8. 출처·신뢰등급·정정: 점수와 독립된 메타데이터로 본문/후반에 명시.

## 5. 페이지 레이아웃
- A4 세로 210×297mm, 흰색/따뜻한 백색 종이 느낌, 시그널 블루 #2458F5 중심, 남색 글자와 옅은 블루그레이 구획.
- 내지: 브랜드 헤더 → 영문 키커 → 제목 → 관측 자료/차트 → 해설 블록 → 한계 또는 다음 검증 질문 → 페이지 번호·고정 푸터.
- 비슷한 2개 도표는 비교 목적이 분명할 때만 함께 배치한다. 제목과 표를 지나치게 떨어뜨리지 않는다.
- 중심 대상은 시그널 블루, 비교 A는 블루그레이, 비교 B는 로즈그레이의 시각적 식별. 각 색상은 가치 수준이나 점수 등급을 의미하지 않는다.
- 모바일 미리보기는 재흐름(reflow) 화면으로 읽되 저장 PDF는 고정 A4를 유지한다.
- 길이가 긴 문장은 글꼴을 6pt까지 억지로 줄이는 대신 페이지를 추가하거나 해설 구획을 분리한다.
