# BRIDGE 검증 프레임워크

상태: 운영 기준  
적용 범위: CPR·GOV·UNI·ENT  
원칙: 이 문서는 점수 엔진, 축 가중치, 공개 적격 기준을 변경하지 않는다. 검증은 산출 결과를 독립적으로 점검하고, 통과하지 못한 주장은 공개하지 않기 위한 품질 체계다.

## 1. 대외 정의와 지식재산 경계

BRIDGE 브랜드평판지수는 공개자료와 공중의 관측 신호를 바탕으로 브랜드와 공중 사이의 관계 상태, 구성과 변화 방향을 반복 관측하는 관계 기반 평판지수다.

외부에는 축의 개념, 자료 범위, 기준기간, 근거 상태, 신뢰등급, 정정 원칙과 해석 한계를 설명한다. 세부 가중치, 임계값, 검색식, 출처별 보정치, 내부 품질 코드와 탐지 규칙은 재현 공격과 모방을 막기 위해 공개하지 않는다. 비공개는 불확실성을 숨기는 수단이 아니며, 공개 해석에 영향을 주는 관측 범위와 근거 상태는 반드시 독자가 이해할 수 있는 언어로 제시한다.

## 2. 검증 체계

| 검증 | 핵심 질문 | 최소 설계 | 내부 산출물 | 공개 원칙 |
|---|---|---|---|---|
| 구성타당도 | 각 자료가 지정된 BRIDGE 축을 실제로 설명하는가 | 축별 코드북, 전문가 이중분류, 불일치 재심 | 축-자료 적합도, 오분류표 | 검증 완료 범위만 해당 축의 관측값으로 표현 |
| 변별타당도 | B/R, I/D, G/단순 활동량이 구별되는가 | 축간 상관, 중복 기여, 분류 혼동 점검 | 상관·중복·혼동 보고서 | 축이 완전히 독립적이라고 주장하지 않음 |
| 수렴타당도 | 외부 기준과 기대 방향의 관계가 있는가 | 공식 만족도·설문·전문평가와 시차를 둔 비교 | 분야별 상관과 신뢰구간 | 독립 표본에서 확인되기 전 정확성 우위 주장 금지 |
| 사건타당도 | 알려진 사건 전후 축이 이론적 방향으로 움직이는가 | 사전등록 사건 목록, 사건창, 통제기간 비교 | 사건별 변화표와 반례 | 인과관계가 아니라 사건 전후 관측으로 표현 |
| 강건성 | 출처·가중치 변화에 결과가 과도하게 좌우되는가 | 출처 하나씩 제외, 허용 범위 내 민감도 분석 | 순위·축 변화 분포 | 불안정 결과는 확정 서술 금지 |
| 결측 편향 | 자료량이 많은 대상이 자동으로 유리한가 | 관측량 구간별 점수·순위·신뢰등급 비교 | 노출-점수 편향 보고서 | 미관측을 0 또는 낮은 평판으로 표현하지 않음 |
| 귀속 정확도 | 신호가 정확한 대상에 연결되었는가 | 동명이인·계열사·병원·기관개편 골든셋 | 오귀속률, 보류·정정 목록 | 불명확 귀속은 산출에서 보류 |
| 시간 안정성 | 동일 입력 재실행은 같고 실제 변화와 수집 변동은 구별되는가 | 결정적 재실행, 스냅샷 해시, 수집 변동 점검 | 재현성·드리프트 보고서 | 근거 범위 변화와 관계 변화를 분리해 설명 |

## 3. 단계별 판정

각 검증은 `NOT_STARTED`, `PILOT`, `PASS`, `WATCH`, `FAIL` 중 하나로 기록한다.

- `PASS`: 사전 정의 표본·절차·허용범위를 충족했다.
- `WATCH`: 운영은 가능하지만 분야 또는 축별 제한을 기사와 신뢰등급에 반영한다.
- `FAIL`: 관련 축의 신규 공개 또는 확정적 해석을 보류한다.
- 검증하지 않은 항목은 검증된 것으로 표현하지 않는다.
- 통계적 유의성만으로 실질적 의미를 확정하지 않고 효과크기·신뢰구간·반례를 함께 본다.


## 3-1. 동적 대상군과 신규 후보 검증

T100 및 각 세부 순위의 비교 대상은 고정 모집단이 아니다. 현재 등록된 대상만 반복 측정하면 신규 등장자와 급격한 관계 변화를 구조적으로 배제하므로, 이는 전체 분야의 상대 위치가 아니라 폐쇄된 명부 내부 순위에 그친다. 특히 80~100위 경계에서는 후보의 진입·이탈 가능성을 매일 점검한다.

2026년 10월 20일부터 CPR·GOV·UNI·ENT 전 분야에 다음 일일 절차를 적용한다.

1. 현재 대상 원장 등록 여부 확인
2. 정식명·영문명·약칭·이전명·그룹/멤버·상위/하위 브랜드 별칭 확인
3. 최근 3일 원시 수집 신호 존재와 수집 성공 여부 분리 확인
4. 동일 기사 안의 다른 등록 대상에게만 귀속되지 않았는지 점검
5. 분야·세부군 자격과 비교 가능한 관측 범위 검토
6. 검증된 후보만 다음 산출일부터 대상 원장으로 승격

신규 후보는 `bridge_entity_candidates`에 서브 데이터로 보존한다. 최소 필드는 분야, 제안 정식명, 별칭, 최초·최종 관측시각, 최근 관측량, 서로 다른 발행처 수, 근거 참조, 동명이인·중복·귀속 불확실성, 검토 상태다. 후보 자료는 점수와 순위에 직접 투입하지 않으며 공개 순위 자동 편입의 근거가 아니다.

검토 우선순위는 변화 속도가 가장 빠른 ENT, GOV, CPR, UNI 순으로 운영하되 모든 분야를 매일 확인한다. 이 우선순위는 심사 속도만 조정하며 공개 적격 기준·점수 엔진·신뢰등급 기준을 낮추지 않는다. 신규 승격은 식별·별칭·중복·분야 적격·근거 연결을 통과하고 적용일이 기록된 경우에만 허용한다. 이미 공개된 과거 회차는 새 후보를 넣기 위해 다시 쓰지 않는다.

일일 상태 보고에는 분야별 발견 실행 성공 여부와 후보 수를 0건까지 명시한다. 후보가 0건이라는 결과와 후보 탐지가 실행되지 않았거나 특정 분야를 건너뛴 상태를 동일하게 취급하지 않는다.

## 4. PUBLICITY 편집 규칙

1. 제목은 1위와 점수를 주목 장치로 사용할 수 있다.
2. 본문 첫 단락에서 해당 순위가 기준기간과 공개 적격 비교 집합 안의 상대 위치임을 밝힌다.
3. 두 번째 단락에서 여섯 축의 구성, 직전 비교 가능한 축 변화, 근거 상태 변화를 설명한다.
4. 비교 기준이 없으면 변화를 추정하지 않고 현재 관계 구성 중심의 회차라고 명시한다.
5. 활동량과 평판 수준, 실제 관계 변화와 확인 범위 확대를 분리한다.
6. T100은 고정 모집단이 아니며 기준일과 관측 상태에 따라 구성이 달라질 수 있다고 자연스럽게 설명한다.
7. ‘자료 부족’이라는 대상 평가형 표현 대신 ‘관측 범위’, ‘근거 상태’, ‘확인 범위’를 사용한다.
8. 내부 결측 코드나 보호된 산식은 기사에 노출하지 않는다.

## 5. 변경·정정·이의제기 기록

내부 기록은 최소한 대상 식별자, 분야, 기준일, 방법론 버전, 입력 스냅샷 해시, 산출 버전, 변경 전후 값, 변경 사유, 검토자, 승인 시각, 공개 영향, 정정 여부를 포함한다. 동일 입력 재실행 결과는 동일해야 하며, 정정은 기존 원장을 덮어쓰지 않고 새 버전으로 연결한다.

## 6. 현재 방어 가능한 주장

- 관계 기반 다차원 평판 관측체계
- 공개자료와 관측 신호의 구조화
- 활동량과 평판 수준의 분리
- 근거 상태와 신뢰등급의 병기
- 수집 실패와 무언급, 0과 미관측의 구분
- 시점·버전·정정 이력 관리
- 분야별 해석 범위 구분

다음 주장은 독립 검증 전 사용하지 않는다: 국내 최고·가장 정확함, 모든 공중의 실제 인식 측정, 완전한 객관성, 여섯 축의 완전한 통계적 독립, 모든 축의 실측, 미래 성과 예측, 서로 다른 분야의 단일 척도 우열 비교, 과학적 타당성의 완전한 입증.

## 7. 완료 조건

‘검증 완료’는 문서 존재가 아니라 사전 정의된 표본, 실행 로그, 결과표, 반례 검토, 승인 기록이 함께 존재할 때만 선언한다. 현재 데이터가 없는 검증은 설계 완료로만 기록하며 결과를 추정하지 않는다.

## Weekly observability validation

From 2026-W43, validation separates measurement coverage from collection
completion.

1. Every active entity-axis must have O, M, R or F for the current week.
2. O and M are score-available; R is honestly excluded; F is an operating
   failure requiring diagnosis.
3. Weekly comparisons must disclose scope expansion, reduction or change.
4. Consecutive reference streaks must enter the staged remediation queue.
5. Domain validation reports must include six-axis coverage distributions,
   full-coverage rate, reference streaks and collection failures.
6. A higher coverage rate is not accepted as improvement if attribution,
   deduplication, construct validity or source independence deteriorates.
7. New domain indicators remain parallel/shadow evidence until robustness and
   direction tests confirm that they improve explanation without destabilizing
   rank mechanically.

The operational chain for each research-derived indicator is: theoretical
construct → operational definition → observable indicator → source family →
collection cadence → attribution → deduplication → validity period → axis
mapping → confidence. A concept that cannot complete this chain is not admitted
to scoring.
