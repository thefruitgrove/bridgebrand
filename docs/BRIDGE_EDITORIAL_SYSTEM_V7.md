# BRIDGE Public Language & Editorial Standard v7.1

이 문서는 **홈페이지 문구 사전, 보고서 문체 규격, PUBLICITY 편집 규격, 금지·조건부·권장 용어집**을 하나로 묶은 공식 명세다. 공개 문장을 작성하는 사람과 자동 생성기는 모두 이 문서를 기준으로 삼는다. 화면의 문구, PDF 보고서와 PUBLICITY가 서로 다른 목소리를 내더라도 사실의 정의와 해석의 경계는 같아야 한다.

## 1. 적용 범위

이 규격은 홈페이지, BRIDGE INTELLIGENCE, 구독 안내, 웹·PDF 브리핑과 PUBLICITY의 공개 문장에 적용한다. 점수 엔진, 근거 원장, 가중치, 공개 적격 기준은 변경하지 않는다.

## 2. 편집 원칙

1. 순위로 독자의 시선을 열되 순위만으로 평판을 단정하지 않는다.
2. 쉬운 해석은 공식 개념을 바꾸지 않으며 전문가 분석으로 들어가는 입구가 된다.
3. 활동량·평판 수준·순위·신뢰등급·축 상태를 서로 대신하는 값으로 쓰지 않는다.
4. 사실, 비교, 제한 해석, 가설, 한계, 관측 질문과 전략 선택지를 구분한다.
5. 직접 근거가 없는 원인·감정·인과·미래 점수는 생성하지 않는다.
6. 분야별 조작적 정의를 적용하되 CPR·GOV·UNI·ENT 사이의 점수를 직접 비교하지 않는다.
7. 세부 가중치·임계값·수집 전략은 공개하지 않으며, 개념·기준기간·근거 상태·해석 범위는 설명한다.

## 3. 참고 보고서의 역할 분담

- NIA형: 거시 구조, 목차, 카드와 다이어그램의 정보 배치
- 자본시장연구원형: 판단 조건, 논증, 대안 해석, 한계와 시사점
- KB형: 표·그래프의 수치를 독자가 이해할 문장으로 번역
- KOBACO형: 생소한 개념을 정의·사례·활용 순서로 설명

한 문단에 네 문체를 모두 혼합하지 않는다. 화면 또는 페이지의 기능에 따라 주된 문체를 하나 선택한다.

## 4. 문장 데이터 계약

공개 문장은 다음 필드를 확인한 뒤 생성한다.

- 분야·대상·기준일·비교집합
- 순위·점수·전일 및 전주 비교 가능 여부
- B·R·I·D·G·E 값과 관측·유지·참조 상태
- 산출축 수·축 커버리지·근거 신뢰등급
- 활동량과 활동 기준기간
- 사건 귀속·중복 제거·근거 ID
- 방법론 버전과 관측기간

## 5. 주장 등급

| 등급 | 기능 | 권장 표현 |
|---|---|---|
| FACT | 공개 데이터의 사실 | 기록했다, 집계됐다, 확인됐다 |
| COMPARISON | 같은 조건의 비교 | 앞섰다, 낮았다, 차이가 났다 |
| INTERPRETATION | 근거가 허용하는 의미 | 보여준다, 의미한다, 읽을 수 있다 |
| HYPOTHESIS | 아직 검증되지 않은 설명 | 가능성을 남긴다, 추가 확인이 필요하다 |
| LIMITATION | 해석의 경계 | 현재 근거만으로 판단하기 어렵다 |
| RECOMMENDATION | 실행 선택지 | 우선 검토할 수 있다, 확인 기준으로 삼을 수 있다 |

신뢰등급 하나만으로 주장 강도를 결정하지 않는다. 신뢰등급, 비교 가능성, 근거의 직접성, 주장 유형을 함께 확인한다.

## 6. 페이지별 전개

- SIGNAL GUIDE: 생활 질문 → 공식 정의 → 예시 → 오해 방지
- CURRENT VIEW: 현재 목록 → 비교 조건 → 주요 분포 → 이번 주 확인점
- POSITION READ: 순위 → 점수 → 비교집합 → 축 커버리지 → 판단 경계
- RELATIONSHIP INTELLIGENCE: 강한 축 → 낮은 축 → 유효한 축 조합 → 대안 해석 → 실무 선택지
- PUBLICITY BRIEF: 관심 장치 → 기준 사실 → 여섯 축 → 변화와 활동량 → 한계 → 다음 질문
- REPORT EDITION: 모든 표·그림마다 독립 해설을 제공하고 화면보다 상세한 근거와 해석 범위를 보존

역할은 유지하되 같은 배열을 연속 두 페이지에서 반복하지 않는다.

## 7. 시각자료 설명 계약

각 표·그래프·도표·다이어그램은 다음을 설명한다.

1. 무엇을 보여주는가
2. 어디를 먼저 봐야 하는가
3. 가장 큰 차이 또는 예외는 무엇인가
4. 무엇을 의미하는가
5. 어디까지 해석할 수 있는가
6. 다음 회차에서 무엇을 확인할 것인가

표의 수치를 순서대로 읽는 문장은 분석문장으로 세지 않는다.

## 8. 언어 QA

- 동일 종결어가 세 문장 이상 이어지지 않게 한다.
- `이를 통해`, `따라서`, `한편`, `이러한 구조는`의 기계적 반복을 검사한다.
- 대상명만 바꿔도 성립하는 일반론은 재작성한다.
- 표의 숫자를 단순 낭독하거나 같은 사실을 유사어로 반복하지 않는다.
- `완벽`, `오차 없이`, `압도적`, `독보적`, `유일`, `진짜 평판`, `철옹성`, `구조적 비밀`은 공개 문장에서 차단한다.
- 유행어와 전문용어는 관련 근거가 존재하고 공식 의미가 일치할 때만 사용한다.

## 9. 발행 게이트

원장 → 점수 → 공개 JSON → 화면 → 보고서 → PUBLICITY의 대상·날짜·값·축 상태가 일치해야 한다. 참조축은 점수와 강·약점 판단에서 제외한다. 진행 중 주간과 완료 주간을 같은 조건처럼 비교하지 않는다. 문장 QA와 데이터 QA 중 하나라도 실패하면 발행을 보류한다.

## 10. 홈페이지 문구 사전

홈페이지는 사용자가 5초 안에 `무엇을 측정하는가`, `숫자가 무엇인가`, `어디까지 믿을 수 있는가`를 파악하게 해야 한다. 한 화면에서 철학적 슬로건과 방법론 설명을 반복하지 않는다.

| 개념 | 공식 표기 | 쉬운 설명 | 쓰지 않는 대체어 |
|---|---|---|---|
| BRIDGE | 관계 기반 평판지수 | 공개자료에서 확인되는 관계의 현재 수준과 구성을 읽는 지수 | 마음 측정기, 진짜 평판 |
| DAILY INDEX | 오늘의 관측 가능한 관계 평판 수준 | 기준일에 유효한 축을 반영한 당일 지수 | 오늘의 인기점수 |
| WEEKLY INDEX | 진행 중 주간 대표지수 | 월요일부터 현재까지 일별지수의 근거 신뢰도 가중평균 | 이번 주 최고점 |
| ACTIVITY POINTS | 검증된 사건 활동량 | 귀속과 중복 제거를 거친 움직임의 규모 | 호감도, 긍정점수 |
| 순위 | 동일 조건의 상대적 위치 | 같은 분야·날짜·공개 범위에서의 위치 | 절대 우열, 능력 순위 |
| 근거 신뢰등급 | 산출 근거의 충실성 등급 | 결과를 어디까지 해석할 수 있는지 돕는 표지 | 평판등급, 품질보증 |
| 관측 | 해당 날짜의 유효 근거로 산출 | 당일 근거가 확인된 축 | 확정 |
| 유지 | 유효기간 내 근거를 규칙에 따라 재확인 | 이전 근거가 아직 유효한 축 | 추정 |
| 참조 | 유효 평가값 없이 중립선만 표시 | 종합지수와 순위에서 제외되는 축 | 50점 평가 |

홈페이지의 핵심 동사는 `관측한다`, `구분한다`, `설명한다`, `확인한다`로 제한한다. `증명한다`, `보장한다`, `예측한다`, `판정한다`는 해당 기능과 검증 근거가 있을 때만 쓴다.

## 11. 보고서 문체 규격

보고서는 의사결정을 돕는 분석 문서다. 한 페이지의 기본 전개는 `질문 → 확인된 사실 → 비교 조건 → 제한 해석 → 활용 제안 → 다음 관측`이다. 모든 페이지가 이 여섯 단계를 기계적으로 반복할 필요는 없지만, 두 페이지 안에는 여섯 기능이 모두 나타나야 한다.

- 쉬운 해석은 생활 질문과 짧은 예시로 시작한다. 공식 축 이름과 정의는 바꾸지 않는다.
- 전문가 분석은 수치·기간·비교집합·근거 상태를 먼저 명시한 뒤 판단한다.
- 중심 대상의 장점은 비교 대상의 약점을 만들어서 강조하지 않는다.
- 낮은 축은 결함이 아니라 `현재 공개 근거에서 상대적으로 덜 선명한 축`으로 설명한다.
- 전략은 점수 상승 처방이 아니라 `확인할 접점`, `확보할 근거`, `검증할 실행`으로 쓴다.
- 21페이지는 최소 편집량이다. 근거가 없으면 원인을 늘리지 않고 비교조건·근거지도·대안 가설·다음 관측으로 설명 밀도를 확보한다.
- 표와 그림을 읽어주는 문장은 분석문장 수에 포함하지 않는다.

문단은 3~5문장으로 구성한다. 첫 문장은 문단의 판단을, 가운데 문장은 근거와 예외를, 마지막 문장은 활용 또는 다음 질문을 맡는다. 같은 대상명이나 `BRIDGE`로 세 문장을 연속 시작하지 않는다.

## 12. PUBLICITY 편집 규격

PUBLICITY는 보고서의 축약본이 아니라 공개 독자를 위한 독립 기사다. 제목은 순위·점수 같은 관심 장치를 사용할 수 있지만, 본문은 그 수치가 만들어진 조건과 여섯 축의 차이를 설명해야 한다.

1. 제목: 대상·위치·핵심 해석 포인트를 한 문장에 담는다.
2. 리드: 기준일, 분야, 공개 적격 수, 선두 또는 중심 결과를 밝힌다.
3. 기준 사실: 순위와 점수의 비교 조건을 설명한다.
4. 축 해석: 가장 선명한 축과 확인할 축을 함께 다룬다.
5. 변화 판독: 실제 값 변화와 근거 범위 변화를 구분한다.
6. 활동량: 사건 규모와 평판 수준이 다른 값임을 밝힌다.
7. 비교·분포: 상위권 간격과 근접군을 과장 없이 설명한다.
8. 한계·다음 질문: 다음 회차에서 검증할 항목으로 닫는다.

기사 문장은 일반 독자가 처음 읽어도 이해할 수 있어야 한다. 다만 `마음`, `온도`, `날씨`, `생체신호` 같은 비유는 제목이나 도입에서 한 번만 사용할 수 있고 공식 지표명으로 치환하지 않는다. 기사에서 `실무적 시사점`, `관계 구조`, `입체적`, `유기적`을 반복하는 대신 무엇이 누구에게 어떻게 연결되는지를 구체적으로 쓴다.

## 13. 금지·조건부·권장 용어집

### 금지

`진짜 평판`, `마음을 측정한다`, `완벽·완전`, `오차 없이`, `압도적`, `독보적`, `철옹성`, `유일한 해답·나침반`, `구조적 비밀`, `객관성을 보장한다`, `통계적으로 증명한다`, `반드시 반등한다`.

### 조건부

- `원인`: 사건 귀속과 전후 축 변화가 확인된 경우만 사용한다. 그렇지 않으면 `함께 관측된 변화`, `확인할 가능성`으로 쓴다.
- `신뢰`: E축 또는 근거 신뢰등급 중 무엇을 뜻하는지 명시한다.
- `강점·약점`: 유효 축과 같은 비교조건일 때만 사용하며, 공개문에서는 `높게 관측된 축·확인할 축`을 우선한다.
- `전망·예측`: 검증된 예측모형이 없으면 사용하지 않는다. `다음 회차에서 확인한다`로 바꾼다.
- `긍정·부정`: 감성 또는 방향 근거가 있을 때만 사용한다. 활동량으로 추정하지 않는다.
- `트렌드`: 최소 반복 관측기간을 명시할 수 있을 때만 쓴다.

### 권장

`기준일`, `동일 분야`, `공개 범위`, `관측됐다`, `확인됐다`, `구분해 읽는다`, `직접 근거`, `비교 가능`, `제한 해석`, `대안 설명`, `다음 관측 질문`, `활용 선택지`, `축별 프로필`, `관계 형성 방식`.

## 14. 마케팅·브랜드·데이터 분석 용어 사용 기준

전문용어는 글을 고급스럽게 보이게 하는 장식이 아니라 정확한 개념을 짧게 전달할 때만 쓴다.

- 브랜드: 정체성, 연상, 접점, 경험, 행동 전환, 책임 이행, 관계 유지
- 마케팅: 도달, 반응, 참여, 전환, 재참여, 접점 설계, 메시지 일관성
- 데이터 분석: 기준기간, 비교집합, 분포, 변동, 커버리지, 귀속, 중복 제거, 결측, 재현성

`초개인화`, `미닝아웃`, `AX`, `ESG`, `팬덤`, `바이럴` 등 유행·분야 용어는 실제 근거가 그 개념을 측정할 때만 사용한다. 모든 분야에 같은 전문용어를 복사하지 않는다.

## 15. 주어·동사·종결어 규칙

| 문장 기능 | 권장 주어 | 권장 동사·종결 | 피할 표현 |
|---|---|---|---|
| 사실 | 공개 데이터, 해당 축, 이번 회차 | 기록했다, 관측됐다, 집계됐다 | 입증했다, 증명했다 |
| 비교 | 두 값, 비교집합, 직전 회차 | 높았다, 차이가 났다, 달라졌다 | 압도했다, 추월의 의미를 과장 |
| 해석 | 이 차이, 현재 프로필 | 보여준다, 시사한다, 읽을 수 있다 | 분명히 말한다, 단정된다 |
| 한계 | 현재 근거, 비교 조건 | 판단하기 어렵다, 확인되지 않았다 | 데이터가 없다, 의미가 없다 |
| 권고 | 담당자, 다음 회차, 분석자는 | 우선 확인할 수 있다, 검토해야 한다 | 반드시 해야 한다, 성공한다 |

문장 끝은 확신의 강도가 아니라 근거의 강도에 맞춘다. 단정형을 늘리는 것으로 전문성을 만들지 않는다. `~수 있습니다`가 연속되면 하나는 사실형, 하나는 질문형으로 바꾼다.

## 16. AI 문체 자동 검사 규칙

다음 항목은 발행 전 경고 또는 차단 대상이다.

- 금지어 한 건 이상: 차단
- 대상명만 바꾸면 성립하는 일반론이 한 페이지의 절반 이상: 차단
- 같은 접속어 네 번 초과: 경고
- 같은 종결어 여섯 번 초과: 경고
- `관계 구조`, `입체적`, `유기적`, `실무적 시사점`을 각각 세 번 초과: 경고
- 한 문장 120자 초과가 연속 두 번: 경고
- 숫자 없는 비교문, 기간 없는 변화문, 근거 없는 원인문: 차단
- 표의 행을 같은 순서로 다시 읽는 문단: 재작성
- 모든 문단이 동일한 문장 수와 배열을 갖는 경우: 재작성

자동 검사는 글의 품질을 보장하지 않는다. 통과 결과는 최소 안전선이며 최종 편집자는 문맥, 리듬, 대상별 고유성을 다시 확인한다.

## 17. 시각자료 사용 규칙

시각자료는 장식이 아니라 질문에 답해야 한다. 순위표는 `누가 어디에 있는가`, 분포도는 `간격과 근접군은 어떠한가`, 레이더는 `축별 모양이 어떻게 다른가`, 시계열은 `언제 무엇이 달라졌는가`, 근거지도는 `어떤 자료가 어느 축을 뒷받침하는가`에 사용한다.

- 한 시각자료에는 한 가지 중심 질문만 둔다.
- 축·단위·기간·표본 또는 공개집합을 표시한다.
- 색상만으로 상태를 구분하지 않고 문자나 기호를 병기한다.
- 참조값은 실측값과 다른 선·채움·레이블로 표시한다.
- 그래프 아래에는 `보이는 사실`, `허용되는 해석`, `해석하면 안 되는 것`을 각각 한 문장 이상 둔다.
- 모바일에서는 표를 무리하게 축소하지 않고 카드 또는 가로 스크롤로 바꾼다.
- PDF에서는 표·그림과 해설이 다른 페이지로 분리되지 않게 한다.

## 18. 채널별 문체 분리

| 채널 | 주 독자 | 문체 | 핵심 산출물 |
|---|---|---|---|
| 홈페이지 | 처음 방문한 일반인·실무자 | 짧고 정의 중심 | 무엇·왜·어떻게 읽는지 |
| BASIC | 단일 대상을 빠르게 확인하는 독자 | 간결한 설명형 | 핵심지표·6축·근거·다음 질문 |
| STANDARD | 비교와 판단이 필요한 독자 | 설명형+분석형 | 동일 조건 비교·한계·활용 제안 |
| SPECIAL | 전략 의사결정자 | 분석형+자문형 | 3일 흐름·과거 PUBLICITY·전략 선택지 |
| PUBLICITY | 공개 기사 독자 | 기사형 | 관심 장치·핵심 사실·맥락·다음 관측 |

보고서 문장을 그대로 PUBLICITY에 복사하거나, PUBLICITY의 헤드라인 문체를 보고서 본문에 반복하지 않는다.

## 19. 글 작성 시스템

생성 순서는 `데이터 검증 → 사실 카드 → 주장 등급 → 독자·채널 선택 → 문단 설계 → 시각자료 해설 → 언어 QA → 교차 검증 → 발행`이다. 생성기는 먼저 사실 카드(JSON)를 만들고, 그 카드에 없는 날짜·원인·평가·전망을 문장으로 만들지 않는다. 각 문장은 내부적으로 `FACT`, `COMPARISON`, `INTERPRETATION`, `HYPOTHESIS`, `LIMITATION`, `RECOMMENDATION` 태그를 가진다.

최종 교차 검증에서는 동일 대상의 화면, PDF와 PUBLICITY가 같은 날짜·점수·순위·축 상태를 쓰는지 확인한다. 표현은 채널에 맞게 달라도 사실은 달라질 수 없다.

## 20. 놓치기 쉬운 중요 사항

- 접근성: 색약, 작은 화면, 스크린리더와 인쇄 환경을 함께 확인한다.
- 법적·윤리적 경계: 인격·도덕성·능력·투자가치·교육품질을 지수에서 확대 추론하지 않는다.
- 정정 가능성: 문장과 시각자료가 사용한 기준일·버전·근거 범위를 기록한다.
- 번역: 영어·일본어·중국어는 한국어 문장의 직역이 아니라 공식 용어집과 주장 등급을 유지한 현지화로 작성한다.
- 고유성: 분야별 공중과 접점이 문장에 드러나지 않으면 범용 문장으로 판단하고 재작성한다.
- 유지관리: 용어 변경은 문서, 생성기, 테스트와 공개 화면을 같은 버전에서 함께 갱신한다.
