# BRIDGE INTELLIGENCE — 03·04 사용자 중심 서술·화면 구조 개선

기준: 2026-11-15 / 편집 전용 브랜치 `bridge-editorial-standard-v1` / 정식 서비스 배포 전

## 사용자 지시와 구현 범위

동국대학교를 예로 제시한 BRIDGE INTELLIGENCE 개선 요청에 따라, **대상명이나 점수를 하드코딩하지 않고 실제 선택 대상 `pick`을 기준으로** 웹 브리핑 03·04단계의 콘텐츠 생성과 화면 배치를 변경한다. 대상은 대학뿐 아니라 기업·정부 및 공공기관·인물에도 적용할 수 있어야 한다.

### 03 POSITION READ — 요약이 아닌 대상별 해설
1. **01번 앞에 실제 선택 대상의 기준일·분야별 순위·DAILY·비교대상·근거 신뢰등급·관측 상태·해석 한계를 설명하는 4개 상세 문단**을 배치한다. 데이터가 제공하지 않는 이벤트나 인과관계는 삽입하지 않는다.
2. **01~10은 실제 선택 대상의 결과 및 관련 비교를 설명**한다. 기존 19개 글 중 개인화 정보가 포함된 01·02·07·08·09·10·11·12·14·17을 개인화 영역에 재배치하고 기존 번호 대신 화면에서 01~10을 새로 부여한다.
3. **11~19는 누구에게나 적용되는 공통 해석 원칙**을 배치한다. 기존 03·04·05·06·13·15·16·18·19가 여기에 해당하며, 출처를 알 수 없는 개별 사실을 공통론에 섞지 않는다.
4. 두 영역은 은은한 금색 계열의 대상별 분석 카드와 청회색 계열의 일반 원칙 카드로 구분하되, 기존 본문 글씨 크기·브랜드 색상·페이지 구조를 변경하지 않는다.
5. 순위·점수와 신뢰등급을 혼동하지 않으며, 전일 순위가 없으면 `null위`나 존재하지 않는 등락 대신 '비교 보류'를 안내한다.

### 04 RELATIONSHIP INTELLIGENCE — 15개 조합의 대상별 결론
1. 여섯 축의 15개 가능한 조합(B–R, B–I, ... G–E)마다 기존의 해석·근거·실무 점검 설명을 **그대로 유지**하고, 끝에 **'즉, 이것은 [선택 대상]의 ...을 의미합니다/뜻합니다'** 형태의 한정된 결론을 별도 시각 영역으로 추가한다.
2. 두 축 모두 observed/maintained이고 유효 숫자가 있으면 **실제 두 점수의 수준과 격차**를 바탕으로 의미를 정리한다. 점수 격차만으로 인과관계를 단정하지 않는다.
3. 하나라도 참조 상태이면 그 연결을 평가할 **대상별 유효 자료가 부족하여 결론을 보류**한다는 내용으로 마무리한다. 참조 축을 0점/실제 50점으로 해석하지 않는다.
4. 축 조합 15개는 고정된 단어만 바꾼 15종의 가짜 분석이 아니라, 각 조합의 **고유한 관계 질문과 실제 값 또는 근거 부재**가 결론에 반영돼야 한다.

### 04 활동량과 평판 수준 — 개인화 5개 + 공통 해석 8개
1. 기존 13개 설명을 삭제하지 않고 사용자가 선택한 대상의 P, DAILY, 비교 대상과 관련된 사례를 상단 **01~05**로 배치한다.
2. 활동량 산식의 일반 설명, 화제성과 평판의 비동일성, 0P·인과관계 제한 등 공통 해설을 하단 **06~13**에 배치한다.
3. 두 영역은 03 POSITION READ와 같은 디자인 언어로 구분한다.

### 문체 규칙
- **설명형 존댓말(~입니다, ~합니다, ~뜻합니다)**을 웹 브리핑 03·04 단계의 본문 문체로 사용한다. 짧은 목록식 단정형 서술과 본문 경어체를 섞지 않는다.
- 전후 문장 연결이 필요한 경우, 실제 논리관계에 맞는 접속어만 사용하고 같은 접속어를 무의미하게 반복하지 않는다.
- 분석 결과는 **대상명, 기준일, 분야 T100, 평가축 유효성, 신뢰등급과 자료 범위**에 묶는다. 동국대학교라는 이름을 코드에 고정하지 않는다.
- 이번 개선은 **웹 INTELLIGENCE 03·04 단계**이며 PDF 본문 18/29쪽의 내용을 새로 줄이거나 페이지 수와 글씨 크기를 변경하는 작업이 아니다.
