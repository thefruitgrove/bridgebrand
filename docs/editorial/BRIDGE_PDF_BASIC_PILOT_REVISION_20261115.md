# BRIDGE PDF Editorial Pilot — BASIC 본문 1차 개정 검증 원장
2026-11-15 / 브랜치 bridge-editorial-standard-v1 / 현행 site/briefing.js

## 목적과 편집 원칙
대표 PDF 전체를 AI로 새로 만드는 대신 기존 BASIC 18쪽 생성기 안의 **설명이 실제 데이터와 어긋나거나 부족할 수 있는 문장**을 정확하게 수정한다. 국문과 전문가의 교정 원칙은 **설명을 축약하지 않으며, 사실·조건·수치·그래프를 충분히 풀어 쓰는 것**이다.

## 수정된 문장의 편집 품질 검수
- 숫자·점수·순위·신뢰등급·비교조건을 계산하는 원래 로직은 고치지 않았다. 비교의 **표시 문장**에 null guard를 추가했다.
- 기존 시각 구성의 `printPage`, `printTable`, `printProse`, 그래프, 18/29쪽 장수, 6축 정의 자체를 변경하지 않았다.
- 본문을 잘라내거나 핵심 정보를 줄이지 않고 필요한 해설을 늘렸다.
- 페이지 3/4/6/11/13/14의 **레이아웃 넘침**은 아직 실제 PDF 렌더 결과를 확인하지 못했다. 기존 고정 장수에 문장이 추가된 만큼 다음 단계의 중요한 미검증 항목이다.
- 실제 null/이전 데이터 부재 fixture로 PDF를 직접 출력한 것은 아니며, 문자열 및 이전 CI 회귀검사 성공과 구분한다.
- 아래 코드 검사를 통과해도 인간 독자의 이해도가 좋아졌다는 결론은 내릴 수 없다.

## 다음에 실제 출력 검증할 체크리스트
1. 분야별 CPR·GOV·UNI·ENT 실제 대상과 신뢰등급이 다른 사례를 포함.
2. 이전 날짜·이전 순위·점수 변화·주간 비교 상태가 빈 사례에서 ‘null위’, ‘undefined위’, 잘못된 비교 조건 표시 0건.
3. 각 페이지 본문, 표, 차트, 머리글과 주석이 페이지 경계 밖으로 넘치지 않음.
4. 모든 6축 상태를 바르게 표시: observed / maintained / reference. 참조값 50을 강약점으로 읽지 않음.
5. 기존 국문 BASIC 18쪽 및 STANDARD 29쪽, 영문 BASIC 8쪽 및 STANDARD 29쪽을 변형하지 않음.
6. 일반 독자가 점수와 자료 신뢰등급의 차이, 전일 자료 누락의 의미를 정확하게 재진술할 수 있는지 평가.
7. 국문과 교수에게 문단 간 연결과 문체의 자연스러움, 경영·브랜드 전문가에게 판단과 수치 해석의 정확성을 각각 평가받음.
