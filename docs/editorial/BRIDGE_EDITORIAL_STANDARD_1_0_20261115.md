# BRIDGE Editorial Standard 1.0 — 공식 용어·문체·반복 검증 규정

발행일: 2026-11-15. **승인 전 편집 후보 규정**. `BRIDGE Editorial Audit 1.0`와 함께 관리.
경계: 보고서의 글·정보 구조·시각적 전달 방식을 함께 개선하되 계산식, 평가축 코드·명칭, 데이터·날짜, 확정된 PDF 장수와 인과적 판단 범위를 임의로 변경하지 않는다. **정확하고 상세하게 풀어 설명하는 것을 첫 번째 문체 원칙**으로 두며, 압축·요약은 독자가 이해하는 데 실제로 도움이 되는 범위에서만 적용한다.

## 1. 목적
일반 이용자에게는 전문용어의 뜻과 숫자의 의미를 생략하지 않고 **차근차근 풀어 설명**하고, 전문 이용자에게는 그 위에 재현 가능한 수치·비교조건·근거와 해석의 한계를 덧붙인다. 서로 다른 등급의 보고서에는 **같은 분석 사실**을 사용한다. 고급 보고서일수록 표현을 어렵게 만드는 방식은 금지하되, **정보량·해설 깊이·사례·표와 그래프의 설명을 줄여서도 안 된다.** 길이는 무조건 줄이거나 늘릴 목표가 아니다. 필요한 설명을 충분히 제공하고 불필요한 반복만 정리한다.

## 2. 문체 원칙
1. 결과를 먼저 쓴다. ‘누구의 어떤 지표가 언제 얼마이고, 어떤 기준에서 비교하는가’를 우선 배치.
2. 숫자와 해석을 분리한다. ‘R 81.4, D 59.2’는 검증된 수치라고 가정한 *가상 예시*일 때만 쓰며, 원인을 새로 만들지 않는다.
3. 핵심 명사는 일관되게 쓴다. `평가축`, `관측`, `유지`, `참조`, `근거 신뢰등급`, `기준일`, `비교 대상`을 문장마다 임의의 유사어로 바꾸지 않는다.
4. 전문용어는 처음 등장할 때 독자가 이해할 수 있는 **충분한 설명**과 가능하면 실제 지표에 연결되는 사례를 제공한다. 뜻을 한 문장 안에 억지로 압축하지 않고, 무엇을 측정하며 무엇을 뜻하지 않는지 이어서 설명한다.
5. ‘관계의 긴 호흡’, ‘근거가 선명하다’, ‘관계 지형’ 등 비유를 기계적으로 반복하지 않는다. 의미가 불명확하면 지표와 기간을 구체화.
6. 같은 ‘A가 아니라 B’ 대조, 세 개 추상명사 병렬, ‘따라서/다시 말해’ 결말을 여러 페이지에서 반복하지 않는다. 단 법적·방법론적 한계는 삭제하지 않는다.
7. 관측되지 않은 사실은 거꾸로 추정하지 않는다. `reference`/null/빈축의 값은 ‘0점’ ‘낮은 평가’ ‘부정적 인식’이 아니다.
8. ‘원인’, ‘효과’, ‘개선될 것’, ‘입증’은 인과분석·독립 근거가 존재할 때만 사용. 현재 BRIDGE의 관측 차이는 인과관계의 증명이 아니다.
9. 읽기 흐름은 ‘핵심 결과 → 지표의 뜻과 자료 조건 설명 → 같은 기준의 수치와 비교 → 관련 표·그래프를 읽는 방법 → 해석 및 확인할 사항’이다. 사안에 따라 필요한 순서를 조정하되 설명 단계 자체를 단순화하거나 빠뜨리지 않는다. 모든 문단을 동일한 문장 틀에 끼워 넣지 않는다.
10. PDF의 표·그래프·이미지는 단순 장식이 아니라 **분석과 설명의 일부**다. 중요한 수치·차이·예외와 그 의미를 본문에서 충분히 설명한다. 표의 모든 셀을 무의미하게 반복하지는 않되, 도표를 이해하는 데 필요한 값과 비교조건은 생략하지 않는다. 그림·표·이미지에 제목·출처·기준일·주석·대체 설명을 부여한다.

## 4. NGANE에서 가져온 편집 절차의 BRIDGE 맞춤형 변형
NGANE의 *근거묶음 → 대안 후보 → 선택 → 검증 → 수정 → 보류*는 참고하되, 뉴스 기사 8문단, 헤드라인 5유형 강제, 뉴스용 품질점수는 복제하지 않는다.

### BES 1.0 일곱 단계
1. **Evidence Freeze:** entity/date/snapshot/methodology, 공개 가능 근거와 축 상태를 고정한 `evidence_packet` 준비. 공개 URL 부재 시 새로 만들지 않음.
2. **Claim Planning:** 문장별 `claim_type=FACT|COMPARE|INTERPRETATION|LIMIT|NEXT_CHECK`, 근거 경로와 적용 범위를 붙임.
3. **Draft Variants:** 자동생성 여부와 무관하게 필요한 *설명 블록*에 한해 2~3개 대안을 검토. 기존 고정 문장을 모두 AI로 재생성하지 않음.
4. **Deterministic Gate:** 점수·날짜·순위·신뢰등급·축 상태·기간·도메인·적격성 검사. P0 오류는 문체가 아무리 좋아도 즉시 보류.
5. **Editorial Review:** 기계적인 대칭 표현, 추상명사, 한 문장에 과도한 요건 나열, AI식 결론 반복 교정. 공식 전문용어와 단서는 보존.
6. **Reader Review:** 일반 독자 핵심 이해와 경제경영 전문가의 내용 정확성을 별도로 점검. 동일 AI의 자기점검을 독립 평가로 세지 않음.
7. **Render Gate:** BASIC 18p / STANDARD 29p / 영문판의 페이지 넘침, 한글 폰트, 표·차트, 링크, 접근성, 메타데이터 확인. 실패 시 보류.

문체 수정은 우선 2차례까지 시행. 치명적 오류 또는 반복 실패 시 인간 검토로 전환한다. 2차 이후 자동발행 강행 금지.

## 5. 보고서별 서술
- **BASIC:** 입문용이라는 이유로 본문을 지나치게 축약하지 않는다. 대상과 기준일, 점수, 평가축의 뜻, 숫자를 읽는 방법과 해석의 범위를 순서대로 풀어 설명한다. 1개 대상의 프로필을 충분히 이해할 수 있는 **설명형 기본 보고서**로 설계한다.
- **STANDARD:** BASIC과 동일한 사실 경계를 지키면서 세 대상의 비교·기간 흐름·근거·평가축 조합·시각자료 해설을 **더 상세하게** 제공한다. 각 분석 페이지에 핵심 해석을 이해할 수 있는 충분한 문단을 배치하고, 무조건적인 7~10문장 할당도 무조건적인 문장 축소도 하지 않는다.
- **SPECIAL:** 기존 분석보다 **더 깊은 근거·시간 흐름·사례·표·그래프·가능한 대안 해석과 실무적 점검사항**을 제공한다. 비선형·가중·이력·대상 귀속 같은 추가 근거는 검증된 경우에만 활용한다. ‘원인 해설’이라는 상품 약속은 근거 확보 전 금지하며, 상세함을 인과관계 확정과 혼동하지 않는다.
- **영문판:** 동일 사실 경계와 축 상태 유지, 국문판에 없는 인과·서열을 넣지 않는다.

## 6. 품질 평가: 사람 점수와 자동 게이트를 구분
- 이해 용이성 30, 자연스러운 문체 25, 전문적 정확성 25, 명료성 10, 독자 읽기 흐름 10 = 100.
- 이 배점은 **가설적 내부 검수 기준**이며 측정척도로 검증되지 않음.
- P0: 점수/날짜/상태·동일범위·인과 과장/실제 아닌 신뢰등급 표시. 100점이어도 무조건 보류.
- 90 이상: 검토된 샘플 수준의 우수 초안, 80~89: 편집 수정, 80 미만: 재작성 후보. 사람 검수·실제 이해도 시험 없이 자동 확정 금지.
- 품질 상승의 근거: 같은 데이터의 기존/개정판을 모르는 평가자에게 비교 제공하고 ① 핵심 사실을 정확히 말하는 비율 ② 근거 상태를 오해하지 않은 비율 ③ 읽기 부담 평가 ④ 전문가 오류 건수 측정.
- '기계어 완전히 사라짐', '완벽한 글' 같은 절대적 목표를 성과판정으로 사용하지 않는다.

## 6A. 설명의 충분성과 시각 편집 품질(필수 추가 게이트)
- **설명 보존(Explanation Coverage):** 각 분석 블록마다 '무엇을 평가했는가 / 자료 범위는 무엇인가 / 무엇이 관측되었는가 / 왜 비교 가능한가 / 무엇까지 판단할 수 있는가 / 독자가 다음에 확인할 것은 무엇인가' 중 **해당 블록의 목적에 필요한 질문에 실제로 답하는지** 검사한다. 의미가 담긴 문장을 단지 길다는 이유로 삭제하지 않는다.
- **도표-본문 연결:** 차트/표/지도/이미지마다 (a) 왜 필요한가, (b) 가장 중요하게 읽을 지점, (c) 수치·표기 단위·대상·기준일·조건, (d) 예외 또는 해석 한계를 본문에 연결한다. 도표만 삽입하거나 본문에서 재언급하지 않은 시각자료는 품질 결함이다.
- **시각적 정보 계층:** 제목→핵심 판단→충분한 서술→표·그래프→자료 주석→다음 질문의 관계를 페이지와 모바일 화면에서 확인한다. 현재 다크 네이비·골드 톤, 세리프 제목, 브리핑 6단계, 프린트 카드·표·그리드의 디자인 기조를 우선 존중한다.
- **근거·이미지의 정직성:** 실제 보도사진, 기관 로고, 그래프, 개념 일러스트, 생성형 AI 이미지의 성격을 구분한다. 실제 사건을 묘사하는 생성 이미지로 오인되지 않게 하고 이미지의 출처·이용 허락·대체텍스트를 기록한다. 자료가 없는 차트를 예쁜 모양으로 채우지 않는다.
- **레이아웃 검증:** PDF에서는 텍스트 넘침·잘림·고아줄·글꼴 대체·차트/캡션 분리·표 머리글 반복·색 대비·인쇄 안전영역을 검사하고, 모바일에서는 제목 줄바꿈, 가로 스크롤이 필요한 표의 안내, 버튼 크기와 시각적 위계를 점검한다.
- **리듬과 밀도:** 중요 분석은 필요하면 2~3개 문단으로 충분히 설명한다. 장문을 억지로 한 줄 카피로 바꾸거나 매 페이지에 동일 분량을 강요하지 않는다. 긴 설명은 제목·소제목·시각자료·단락 나눔으로 **읽기 편하게 구성**한다.
- **판정 분리:** 지표·근거 오류, 서술 누락, 해석 과장, 도표 수치 오류, 레이아웃 오류는 각각 별도 결함으로 기록한다. 하나의 총점으로 P0 오류를 상쇄하지 않는다.

### 상세 서술을 위한 권장 분석 블록
1. **관측 사실:** 대상과 기준일, 점수/순위 또는 축 상태를 명확하게 제시.
2. **지표의 의미:** 왜 그 지표가 해당 맥락에서 쓰이는지, 관측·유지·참조의 차이가 무엇인지 풀이.
3. **비교·변화:** 같은 조건에서 비교 가능한 대상과 기간의 차이를 구체적 수치로 설명.
4. **시각자료 읽기:** 그래프의 선·축·범례·표의 행열이 무엇을 가리키는지, 눈여겨볼 변화와 예외를 설명.
5. **판단의 경계:** 원인 추정의 한계, 자료의 범위와 추가 확인이 필요한 대목 설명.
6. **후속 검토:** 다음에 어떤 자료를 확보하고 어떤 비교를 해볼지 질문과 확인 경로 제시.

모든 페이지에 6개 항목을 의무적으로 삽입하지 않는다. **해당 페이지의 핵심 메시지가 충분히 설명됐는지를 중심으로 적용한다.** 실제 제시되지 않은 근거를 채우기 위해 문장을 덧붙이지 않는다.

## 7. 버전 및 감사 로그
블록별 `source_path`, `source_span`, `source_sha`, `original_text`, `candidate_text`, `reason`, `claim_type`, `evidence_basis`, `reviewer_role`, `status`, `edition`, `page`를 기록. 편집 규정만 추가했다고 실행기가 자동 다단계 AI 작성을 하게 되었다고 선언하지 않음.

## 9. 중요 한계
NGANE 업로드 규정은 반복 편집·검수·보류 설계를 참고한 내부 사례이며 BRIDGE 원자료나 공식 평판 산출근거로 사용하지 않는다. 최근 경제경영 보고서의 **용어·설명 구조**는 참고할 수 있으나 외부 브랜드 평가사의 지표나 인과 주장으로 BRIDGE의 데이터를 대체하지 않는다.


## 1.1 개정 — 서술의 연결성·충분한 해설·포지셔닝(2026-11-15)

### A. 의미가 이어지는 설명의 기본 구조
- 보고서의 핵심은 **순위나 점수를 보고 바로 결론을 내리는 것이 아니라, 무엇을 평가했고 어떤 자료와 조건으로 그 결과를 읽어야 하는지를 독자가 따라갈 수 있도록 설명하는 것**이다. 한 장의 중요한 도표는 단순한 수치 나열이 아니라 **지표의 뜻 → 실제 관측 결과 → 비교 시 주의사항 → 시각자료를 읽는 기준 → 다음에 확인할 질문**의 자연스러운 맥락을 갖는다.
- 일반인을 대상으로 한다고 해서 중요한 설명을 줄이지 않는다. 개념을 처음 사용할 때에는 쉬운 말로 뜻을 풀고, 관련 지표의 조건과 실제 사례를 연결한다. 같은 내용을 다른 말로 반복해 분량을 늘리는 것도 금지한다.
- **페이지 여백은 자동으로 채울 할당량이 아니다.** 표가 20행인 페이지, 여섯 축의 긴 독립해설 페이지, 페이지 번호와 출처를 위한 하단 공간은 별도로 고려한다. 글자 크기를 줄이거나 이미 안정화한 디자인을 훼손하지 않고, 설명이 부족한 페이지에 필요한 정보만 보충한다.
- 새 자료가 없으면 확인되지 않은 사건, 홍보효과, 이용자 인식, 원인, 장기 예측을 만들어 문장을 늘리지 않는다. 실제 데이터가 뒷받침하는 관측 범위와 방법론적 해설을 상세히 소개하며, 필요한 근거가 없는 구간은 **확인할 질문**으로 남긴다.

### B. 문장 간 연결어 사용 규칙
**권장 표현:** 그러나, 따라서, 그리고, 그런데, 그래서, 또한, 그러므로, 그렇기 때문에, 즉, 한편, 반면, 이러한 점에서, 이와 함께, 무엇보다도, 다만.

1. 연결어를 붙이기 전에 두 문장 사이의 관계를 판정한다. **대조**일 때에는 '그러나/반면/한편', **추가 설명**일 때에는 '또한/이와 함께', **정확한 풀이**일 때에는 '즉/다시 말해', **근거로부터의 타당한 귀결**일 때에만 '따라서/그러므로/그렇기 때문에'를 쓴다. 단지 문장을 부드럽게 만들려고 접속어를 기계적으로 주입하지 않는다.
2. 같은 PDF 페이지에서는 '따라서/그러나/그리고/그런데/그래서/또한/그러므로/그렇기 때문에/즉' **각 표현을 되도록 한 번만 사용**한다. 동일한 연결어가 중복되면 하나를 다른 종류의 연결어로 바꾸기 전에 **문장의 실제 논리 관계부터** 다시 확인한다. 필요한 경우 연결어를 생략하고 문장 구조 자체를 바꾼다.
3. '그렇게 때문에'는 잘못된 표현이므로 사용하지 않고 **'그렇기 때문에'**로 쓴다.
4. 같은 페이지에서 연결어를 전혀 쓰지 않아도 문장이 자연스러우면 강제로 추가하지 않는다. 전체 보고서를 일정한 접속어 순서로 반복하는 것도 기계적인 문체이므로 금지한다.
5. 연결어 중복 검사는 실제 생성된 29쪽 PDF의 **페이지별 본문**을 대상으로 한다. 자동검사는 반복 위험을 선별하는 도구이고, 사람은 논리적 인과·문단 호흡·접속어의 자연스러움을 별도로 확인한다.

### C. 포지셔닝과 방향성 보존
BRIDGE는 **Reputation is a signal.**이라는 관점에서 출발한다. 따라서 주요 소개와 방법론의 설명은 다음 질문을 연결해야 한다.

| 구분 | 실제 보고서에서 설명해야 할 것 | 피해야 할 표현 |
|---|---|---|
| WHAT | 동일 분야·기준일의 위치, 점수, 순위, B·R·I·D·G·E의 구성 | 순위를 가치·능력 전체의 판정으로 소개 |
| WHY | 실제 자료의 출처, 기준기간, 관측/유지/참조 상태, 근거 신뢰등급과 비교조건 | 검증되지 않은 사건의 원인이나 성과를 확정 |
| WHAT NEXT | 현재 공개자료에서 확인되지 않은 영역, 다음 관측 질문과 검증 가능한 실무 점검 | 점수 상승이나 PR 성과를 약속 |

- BRIDGE는 인기 순위만 발표하는 서비스도, 단순히 보기 좋은 잡지나 화보도 아니다. **공개자료를 근거로 브랜드와 공중 사이의 관계 상태와 그 변화를 관측하고, 순위 뒤의 의미를 설명하는 분석 플랫폼**이다.
- **Discover → Intelligence**는 별개 엔진이 아니라 하나의 평가 근거와 지수를 서로 다른 깊이로 경험하는 사용자 여정이다. PDF는 이 여정에서 깊이 있는 설명과 나중에 다시 검토할 수 있는 기록을 제공한다.
- 브랜드 포지셔닝을 매 페이지에 광고문처럼 반복하지 않는다. 5쪽의 공식 접근, 8쪽의 다른 지수와의 차이, 28쪽의 방법론, 29쪽의 기록 책임을 중심으로 **해설 속에 자연스럽게** 녹인다.
- 문장이 아름다워도 평가 수치·근거 상태·자료 시점과 어긋나면 출판할 수 없다.

### D. PDF 시각·본문 함께 검증할 품질 게이트
- **TYPE LOCK:** 기존 최종 확정된 본문 글씨 크기·제목 크기를 임의 변경하지 않는다.
- **NARRATIVE:** 새 문단은 기존 문단과 맥락이 이어지며, 정보의 깊이가 실제로 증가해야 한다. 같은 뜻의 장황한 반복으로 분량을 늘리지 않는다.
- **LAYOUT:** 고정 A4 29쪽 PDF에서 문단/그림/표/캡션이 페이지 하단에 잘리거나 겹치지 않아야 한다. 여백은 지면의 읽기 호흡을 위한 자원이므로 '빈 공간 0'을 목표로 하지 않는다.
- **VISUAL:** 모든 도표는 값·축·단위·범위·표본 생략 정보를 정확하게 전달하고 본문과 일치해야 한다.
- **DATA:** 점수, 순위, 상태, 신뢰등급, 기준일과 공개 스냅샷을 건드리지 않는다.
- **POSITION:** 지수의 포지셔닝, WHAT–WHY–WHAT NEXT의 역할 구분, 발견과 전문해석의 통합 방향을 보존한다.
- **HUMAN:** 국문과 편집자(표현/호흡)·경제경영/브랜드 전문가(개념/해석)·일반 독자(이해도)를 분리 검수한다. 자동검사 통과와 최종 문체 승인을 혼동하지 않는다.
