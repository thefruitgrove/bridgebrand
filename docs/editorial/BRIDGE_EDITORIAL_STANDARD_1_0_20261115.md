# BRIDGE Editorial Standard 1.0 — 공식 용어·문체·반복 검증 규정

발행일: 2026-11-15. **승인 전 편집 후보 규정**. `BRIDGE Editorial Audit 1.0`와 함께 관리.
경계: 보고서의 글을 고치되 계산식, 평가축 코드·명칭, 데이터·날짜, PDF 장수와 인과적 판단 범위를 변경하지 않는다.

## 1. 목적
일반 이용자에게는 핵심 결과를 이해 가능한 언어로, 전문 이용자에게는 재현 가능한 수치·조건과 제한을 제시한다. 서로 다른 등급의 보고서에 **같은 분석 사실**을 쓴다. 문장의 난도와 분량을 높여 고급 상품의 가치로 보이게 하는 접근은 금지.

## 2. 문체 원칙
1. 결과를 먼저 쓴다. ‘누구의 어떤 지표가 언제 얼마이고, 어떤 기준에서 비교하는가’를 우선 배치.
2. 숫자와 해석을 분리한다. ‘R 81.4, D 59.2’는 검증된 수치라고 가정한 *가상 예시*일 때만 쓰며, 원인을 새로 만들지 않는다.
3. 핵심 명사는 일관되게 쓴다. `평가축`, `관측`, `유지`, `참조`, `근거 신뢰등급`, `기준일`, `비교 대상`을 문장마다 임의의 유사어로 바꾸지 않는다.
4. 전문용어는 처음 등장할 때 한 문장으로 설명한다. 바로 뒤에서 독자가 확인할 실제 조건을 말한다.
5. ‘관계의 긴 호흡’, ‘근거가 선명하다’, ‘관계 지형’ 등 비유를 기계적으로 반복하지 않는다. 의미가 불명확하면 지표와 기간을 구체화.
6. 같은 ‘A가 아니라 B’ 대조, 세 개 추상명사 병렬, ‘따라서/다시 말해’ 결말을 여러 페이지에서 반복하지 않는다. 단 법적·방법론적 한계는 삭제하지 않는다.
7. 관측되지 않은 사실은 거꾸로 추정하지 않는다. `reference`/null/빈축의 값은 ‘0점’ ‘낮은 평가’ ‘부정적 인식’이 아니다.
8. ‘원인’, ‘효과’, ‘개선될 것’, ‘입증’은 인과분석·독립 근거가 존재할 때만 사용. 현재 BRIDGE의 관측 차이는 인과관계의 증명이 아니다.
9. 읽기 흐름은 ‘핵심 결과 → 같은 기준의 수치·비교 → 실무적으로 읽을 의미 → 중요한 제한/추가 확인’이며, 모든 문단에 이를 네 문장으로 기계적으로 반복하지 않는다.
10. PDF 표·그래프 수치를 본문에 전부 나열하지 않는다. 가장 설명가치 높은 차이를 선택하고, 비교 범위는 명시한다.

## 3. 공식 용어 사전
|공식 용어|처음 등장할 때 설명|오해·금지 표현|
|---|---|---|
|BRIDGE 평판지수|공개자료에서 확인되는 브랜드와 공중의 관계 신호를 여섯 축으로 살펴본 결과|브랜드의 절대가치·도덕성·매출·미래 성공의 점수|
|평가축 B/R/I/D/G/E|도달·반응·정체성·경험·행동유발·책임과 지속의 여섯 평가 영역|신체 감정 또는 실제 사용자 전원의 심리 직접 측정|
|관측|정해진 자료 및 산출 조건으로 평가값을 얻은 상태|‘실제 모두 조사함’|
|유지|유효기간이 지나지 않은 기존 근거를 규칙에 따라 활용한 상태|당일 신호가 새로 확보됨|
|참조|대상별 유효 평가값이 없어 표시용 기준만 놓은 상태; 점수 계산에서 제외|중립평가 50점, 0점, 결함|
|근거 신뢰등급|그 점수를 뒷받침하는 자료의 범위와 적격성을 안내하는 등급|브랜드의 평판등급|
|활동량 P|정해진 규칙으로 기록한 사건·반응 활동의 규모|긍정 평판, 호감도 또는 판매량|
|DAILY / WEEKLY|당일 지수와 진행/완료 기간이 다른 주간 지수|무조건 같은 기간의 직접 비교|
|동일범위 비교|분야·날짜·모집단·유효 축 등 비교 조건을 맞춰 본 결과|무조건 인과적 차이 설명|
|WHAT NEXT|추가로 확인해야 할 근거와 분석 질문|즉시 효과가 입증된 경영 처방|

## 4. NGANE에서 가져온 편집 절차의 BRIDGE 맞춤형 변형
NGANE의 *근거묶음 → 대안 후보 → 선택 → 검증 → 수정 → 보류*는 참고하되, 뉴스 기사 8문단, 헤드라인 5유형 강제, 뉴스용 품질점수는 복제하지 않는다.

### BES 1.0 일곱 단계
1. **Evidence Freeze:** entity/date/snapshot/methodology, 공개 가능 근거와 축 상태를 고정한 `evidence_packet` 준비. 공개 URL 부재 시 새로 만들지 않음.
2. **Claim Planning:** 문장별 `claim_type=FACT|COMPARE|INTERPRETATION|LIMIT|NEXT_CHECK`, 근거 경로와 적용 범위를 붙임.
3. **Draft Variants:** 자동생성 여부와 무관하게 필요한 *설명 블록*에 한해 2~3개 대안을 검토. 기존 고정 문장을 모두 AI로 재생성하지 않음.
4. **Deterministic Gate:** 점수·날짜·순위·신뢰등급·축 상태·기간·도메인·적격성 검사. P0 오류는 문체가 아무리 좋아도 즉시 보류.
5. **Editorial Review:** 기계적인 대칭 표현, 추상명사, 한 문장에 과도한 요건 나열, AI식 결론 반복 교정. 공식 전문용어와 단서는 보존.
6. **Reader Review:** 일반 독자 핵심 이해와 경제경영 전문가의 내용 정확성을 별도로 점검. 동일 AI의 자기점검을 독립 평가로 세지 않음.
7. **Render Gate:** BASIC 18p / STANDARD 29p / 영문판의 페이지 넘침, 한글 폰트, 표·차트, 링크, 접근성, 메타데이터 확인. 실패 시 보류.

문체 수정은 우선 2차례까지 시행. 치명적 오류 또는 반복 실패 시 인간 검토로 전환한다. 2차 이후 자동발행 강행 금지.

## 5. 보고서별 서술
- **BASIC:** 누구·언제·어떤 점수·상태인가를 먼저 설명. 한 문단에 한 가지 핵심 메시지. 전문 용어는 최초만 풀어씀.
- **STANDARD:** BASIC과 동일한 사실 경계를 유지. 대상 간 차이, 비교 조건, 관련 지표, 설명의 한계를 추가. 각 페이지를 형식적 7~10문장으로 무조건 채우지 않음.
- **SPECIAL:** 비선형·가중·이력·대상 귀속 등 추가 검증된 근거가 있을 때만 심층 분석. ‘원인 해설’이라는 상품 약속은 근거 확보 전 금지.
- **영문판:** 동일 사실 경계와 축 상태 유지, 국문판에 없는 인과·서열을 넣지 않는다.

## 6. 품질 평가: 사람 점수와 자동 게이트를 구분
- 이해 용이성 30, 자연스러운 문체 25, 전문적 정확성 25, 명료성 10, 독자 읽기 흐름 10 = 100.
- 이 배점은 **가설적 내부 검수 기준**이며 측정척도로 검증되지 않음.
- P0: 점수/날짜/상태·동일범위·인과 과장/실제 아닌 신뢰등급 표시. 100점이어도 무조건 보류.
- 90 이상: 검토된 샘플 수준의 우수 초안, 80~89: 편집 수정, 80 미만: 재작성 후보. 사람 검수·실제 이해도 시험 없이 자동 확정 금지.
- 품질 상승의 근거: 같은 데이터의 기존/개정판을 모르는 평가자에게 비교 제공하고 ① 핵심 사실을 정확히 말하는 비율 ② 근거 상태를 오해하지 않은 비율 ③ 읽기 부담 평가 ④ 전문가 오류 건수 측정.
- '기계어 완전히 사라짐', '완벽한 글' 같은 절대적 목표를 성과판정으로 사용하지 않는다.

## 7. 버전 및 감사 로그
블록별 `source_path`, `source_span`, `source_sha`, `original_text`, `candidate_text`, `reason`, `claim_type`, `evidence_basis`, `reviewer_role`, `status`, `edition`, `page`를 기록. 편집 규정만 추가했다고 실행기가 자동 다단계 AI 작성을 하게 되었다고 선언하지 않음.

## 8. 릴리스 게이트와 분리
- 현재 브랜치는 편집전용: `bridge-editorial-standard-v1`.
- 운영 복구 통합 후보 `bridge-integration-candidate-20261115`의 코드/REST/Cloudflare와 자동 병합하지 않음.
- 배포 전 P0 위험, 가장 많이 읽는 홈/상품 카피, BASIC·STANDARD 대표 문장에 집중. 전체 새 AI 문체 엔진은 2.1 과제로 구분.
- 후보별 결과를 4개 분야에 대해 검증한 후 승인. 실제 비운영 PC/모바일/PDF 시각 확인 전 P0 수정도 운영 배포하지 않음.

## 9. 중요 한계
NGANE 업로드 규정은 반복 편집·검수·보류 설계를 참고한 내부 사례이며 BRIDGE 원자료나 공식 평판 산출근거로 사용하지 않는다. 최근 경제경영 보고서의 **용어·설명 구조**는 참고할 수 있으나 외부 브랜드 평가사의 지표나 인과 주장으로 BRIDGE의 데이터를 대체하지 않는다.
