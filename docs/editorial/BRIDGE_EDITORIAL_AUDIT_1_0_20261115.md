- 작성일: 2026-11-15
- 기준: `bridge-integration-candidate-20261115`에서 분기한 `bridge-editorial-standard-v1`
- 대상: `site/bridge-v2.html`, `site/intelligence.html`, `site/briefing.html`, `site/briefing.js`, `presentation/public_copy.py`, `tools/apply_brand_shell.py`
- 범위: 첫 번째 **고위험·고노출 표현 감사**. 128KB `briefing.js`의 모든 동적 문자열에 대한 완전한 문장별 심사, 실물 모바일/인쇄 시안 심사, 독자 실험은 아직 미실시. 이를 전수검사로 오인하지 말 것.

## 우선순위의 의미
- **P0 사실·서비스 약속:** 설명 가능한 범위를 넘어 원인·인과·실효성을 확정하는 표현, 공식 정의 오류, 부정확한 비교.
- **P1 첫 화면·PDF 핵심:** 직접 사용자가 접하는 설명 중 이해를 크게 떨어뜨리는 표현.
- **P2 표현 다듬기:** 의미 보존이 가능한 추상·상투어·영문 과잉·중복 비유.

## 위험 분류
- 사실·기능 표현 과장: ED-001~005, ED-008.
- **실제 데이터/화면 불일치 후보: ED-020.** 선택 대상에 따라 신뢰등급이 달라지므로 하드코딩 문장이 부적절할 가능성이 높다. 동적 바인딩 또는 일반화된 안내로 수정 후 UI 테스트.
- 국문·독자 이해: ED-006~014, ED-017, ED-019.
- 보존할 카피: ED-015, ED-016, ED-018.

## NGANE에서 참고하되 그대로 이식하지 않을 것
- 채택: 입력 근거 고정, 표현 후보 2~3개, 수치·조건·분석 범위 교차검증, 문체 편집, 최대 두 차례 자동 재교정 후 사람에게 이관, 수정 전후·선택 이유 기록.
- 비채택: 뉴스 기사 8문단·기사 헤드라인 유형의 강제, 뉴스 기사 품질 문턱점수의 무검증 전용, 모든 PDF 페이지를 모델로 즉석 재생성.
- 검증되지 않은 주장: AI 다회 호출로 '기계어 완전 제거' 및 품질 무오류가 보장된다는 주장은 채택하지 않는다.

## 변경 순서
1. P0의 거짓·과장·하드코딩 위험부터 별도 편집 브랜치에 수정.
2. 상품 카피와 PDF 핵심 문장을 대상으로 자연스러운 직접 설명형 2~3후보 작성.
3. 4분야 × 결측·유지·관측 조합 표본으로 의미 불변 검증. 실제 점수·날짜·신뢰등급 확인.
4. BASIC 18·STANDARD 29 및 영문 PDF 출력·페이지 수·폰트·줄바꿈 확인.
5. 전문가 검수(정확성)와 일반 독자 검수(이해도) 기록 후 적용.
6. 운영 복구 브랜치와 임의 병합하지 않고, 배포 승인 게이트에 변경된 문장 목록과 회귀테스트를 포함.
