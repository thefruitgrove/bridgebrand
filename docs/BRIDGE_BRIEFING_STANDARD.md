# BRIDGE 브리핑 제작 시스템 표준

## 1. 목적과 적용 범위

이 문서는 BRIDGE 기본·일반·스페셜 브리핑의 목록, 구조, 분석 방식, 글쓰기, 페이지 구성, 표와 시각자료의 배치 및 검수 기준을 규정한다. ENT에서 확립한 형식을 CPR·GOV·UNI에도 동일하게 적용하되, 공통 6축과 근거 원칙은 유지하고 각 분야의 2차 보완층으로 해석만 조정한다.

모든 브리핑은 다음 다섯 단계로 전개한다.

> 이해 → 비교 → 순위 해석 → 실제 분석 → 대외 발표

이 흐름은 단순한 목차가 아니라 독자가 지표를 오해하지 않고 결과에 도달하도록 만드는 논증 순서다. 앞 단계에서 정의하지 않은 용어나 판단을 뒤 단계에서 갑자기 사용하지 않는다.

## 2. 공통 데이터 원칙

- 동일 보고서 안의 수치 비교는 동일 기준일, 동일 분야, 동일 방법론 버전, 동일 공개 범위에서 수행한다.
- 관측·유지 상태만 종합지수와 수치 비교에 사용하고 참조값은 제외한다.
- 순위, 점수, 활동량, 근거 신뢰등급을 서로 다른 개념으로 분리해 설명한다.
- 활동량을 긍정 평판으로 해석하지 않는다.
- 실제 점수 변화와 근거 범위 변화를 구분한다. 비교 범위가 달라지면 변화 해석을 보류한다.
- 낮은 축을 곧바로 부정·실패·도덕성 문제로 해석하지 않는다. 현재 근거 범위에서 상대적으로 약하게 관측된 관계와 부정적 사건을 구분한다.
- 내부 가중치, 비밀키, 임계값, 비공개 원장과 수집 전략은 외부 보고서에 노출하지 않는다.
- 기존 공개 기사를 덮어쓰거나 동일 회차를 중복 발행하지 않는다.

### 이중 독해와 문장 확실성 계약

모든 일반 브리핑 페이지는 `쉬운 해석(EASY READ)`과 `전문가 분석(PROFESSIONAL READ)`을 함께 제공한다. 쉬운 해석은 생활 질문과 비유로 지표에 들어가는 입구이며, 전문가 분석을 대체하거나 점수의 뜻을 바꾸지 않는다. 두 독해는 동일한 기준일·수치·축 상태·신뢰등급을 사용한다.

전문가 분석의 모든 문장은 내부적으로 다음 확실성 중 하나를 갖는다.

| 확실성 | 사용 범위 | 허용 표현 |
|---|---|---|
| 확인 사실 | 공개 스냅샷에서 직접 확인 | `기록됐다`, `관측됐다` |
| 제한 해석 | 확인 사실에서 허용되는 의미 | `현재 범위에서는`, `함께 관측됐다` |
| 검증 가설 | 아직 확인되지 않은 설명 후보 | `다음 회차에서 확인할 질문이다` |
| 실무 권고 | 근거를 바탕으로 한 행동 제안 | `점검하는 편이 타당하다` |

확실성은 기존 문장 역할 태그와 별도로 관리한다. 사실·비교 문장은 근거 키를 가져야 하며, 가설과 권고는 사실처럼 서술하지 않는다. 신뢰등급은 입력된 실제 등급을 그대로 사용하고 보기 좋은 특정 등급으로 고정하지 않는다.

생활 비유는 `성적표가 아니라 반복 관측하는 관계 레이더`, `날씨처럼 현재 상태를 읽는 도구`처럼 제한적으로 사용할 수 있다. 다만 `사람의 마음을 직접 측정한다`, `미래를 예측한다`, `유일·최고·완벽·압도적이다`처럼 관측 범위를 넘어서는 표현은 사용하지 않는다.

### 2.1 BRIDGE 3층 운영 구조

BRIDGE는 다음 세 층을 분리해 운영한다. 아래층의 산출 결과는 위층이 읽을 수 있지만, 위층은 아래층의 값·가중치·적격성·원장을 수정하지 못한다.

1. **공통 점수 산출층** — BRIDGE 6축, 근거 원장, 중복 제거, 공통 가중·정규화, 시점과 버전을 관리한다.
2. **분야별 관측 보완층** — 공통 골격을 유지하면서 ENT·CPR·GOV·UNI의 조작적 정의와 관계 특성을 반영한다.
3. **해석·감사·브리핑층** — 공개된 산출 결과를 받아 순위 이동, 점수 간격, 비교집합, 축 커버리지, 기간 상태를 검사하고 브리핑과 PUBLICITY를 생성한다.

제3층은 설명 가능성과 발행 품질을 높이는 계층이며 점수 엔진이 아니다. 따라서 점수를 다시 계산하거나 신뢰등급을 보기 좋게 바꾸거나, 값 50을 근거 상태로 역추정하거나, 비공개 가중치를 복원해 외부에 노출하지 않는다.

### 2.2 해석·감사층 필수 기능

1. 점수 변화와 순위 변화를 분리해 이동 원인을 분류한다.
2. 점수 간격과 근접 대상을 표시하되 근접 기준은 내부 탐색용이며 통계적 동률로 발표하지 않는다.
3. 회차 간 T100 비교집합의 크기·진입·이탈을 검사한다.
4. 축별 유효 대상 수의 변화를 검사하고 급변 시 실제 변화와 범위 효과의 분리를 요구한다.
5. 진행 중 주간과 완료 주간을 구분한다.
6. 활동량과 관계 평판 수준을 별도 지표로 유지한다.
7. 참조축이 종합·비교·강약 판정에서 제외됐는지 검증한다.
8. 생성 문장의 과장·인과·미정의 용어를 검사한다.
9. 모든 분석문장에 내부 역할 태그를 부여한다.
10. 네 분야별 플레이북과 확대해석 금지 규칙을 적용한다.
11. 발행 전 12문항 체크리스트를 통과시킨다.
12. 일반 브리핑 최소 21페이지 계약을 검증한다.
13. 확인되지 않은 원인 대신 다음 회차 검증 질문을 생성한다.
14. PUBLICITY는 8블록 편집 계약으로 생성·감사한다.

## 3. 브리핑 단계와 대상 선택 규칙

### 3.1 기본 브리핑

- 상품 표기는 `BASIC · 기본 브리핑`으로 통일한다.
- 사용자가 선택한 분석 대상 1개만 다룬다.
- 비교 대상은 포함하지 않는다.
- 핵심 지표, 6축 상태, 강한 축과 낮은 축, 주요 변화, 활동량, 근거 범위, 다음 관측 질문을 설명한다.
- 선택 대상 1개에 관한 짧은 퍼블리시티 1편을 포함한다.
- 2026년 10월 25일 일반 브리핑 확장 전 BRIDGE INTELLIGENCE SERVICE에서 제공하던 단일 대상 중심 구성과 정보 밀도를 기본형의 기준 원형으로 삼는다. 다만 당시 화면이나 문장을 고정 복제하지 않고 최신 공개 데이터·방법론·안전 규칙을 적용한다.
- 기본형은 일반형을 임의로 잘라 낸 결과가 아니다. 한 대상의 현재 상태를 빠르게 이해하는 독립 상품이며, 세 대상 비교·23페이지 장문 해설·복수 대상 퍼블리시티는 포함하지 않는다.

### 3.2 일반 브리핑

- 상품 표기는 `STANDARD · MIN. 21 PAGES · 일반 브리핑`으로 통일한다.
- 사용자가 선택한 중심 대상 1개와 사용자가 직접 선택한 비교 대상 2개를 다룬다.
- 세 대상은 같은 분야의 해당 기준일 T100 안에서만 선택한다.
- 중심 대상은 전체 분석을 제공하고, 비교 대상 2개는 기본 브리핑 수준으로 설명한다.
- 세 대상의 종합 위치, 6축 구조, 가장 큰 차이, 관계 유형, 활동량과 변화 방향을 비교한다.
- 중심 대상을 강조할 수 있으나 동일 기준을 적용하며, 비교 대상을 낮추거나 중심 대상에 유리한 축만 선별하지 않는다.
- 세 대상 전체를 아우르는 독립 퍼블리시티 1편을 포함한다.
- 2026년 10월 25일 완성한 23페이지 웹·PDF 버전을 일반형의 현행 기준본으로 삼는다. 최소 계약은 21페이지이지만 표·그림·도표 해설과 실제 분석량에 따라 22~23페이지 이상으로 자연스럽게 확장할 수 있다.
- POSITION READ의 점수·순위 변화 구간은 기존 핵심 설명에 최소 15개의 추가 풀이 단위를 제공한다. RELATIONSHIP INTELLIGENCE의 활동량·평판 분리 구간은 최소 10개의 독립 해설 단위를 제공한다.
- PDF는 웹 화면을 축약 저장하지 않는다. 모든 주요 표·그림·도표 아래에 `무엇을 보여주는가·무엇을 단정할 수 없는가·어떻게 활용할 것인가`를 설명하는 독립 해설을 배치한다.

### 3.3 스페셜 브리핑

- 상품 표기는 `SPECIAL · MIN. 35 PAGES · 스페셜 브리핑`으로 통일한다.
- 일반 브리핑의 중심 대상 1개와 비교 대상 2개 구조를 기본으로 한다.
- 일반 브리핑의 모든 항목에 표·그림·다이어그램, 축별 변화 원인, 사건 흐름, 근거 상태 변화와 전문 해설을 추가한다.
- 최소 35페이지를 제작·발행 계약으로 적용한다. 35페이지 미만은 스페셜 완성본으로 취급하지 않는다.
- 스페셜의 최우선 추가 가치는 `향후 전략 제안`이다. 전략 제안은 단순 조언이 아니라 확인 사실, 제한 해석, 조건부 가설, 실행 과제, 확인 지표와 다음 관측 질문을 연결한다.
- 변화 원인은 원장에서 확인된 사건·출처·축 상태의 시간 흐름으로 설명한다. 표나 그래프의 동행만으로 인과관계를 선언하지 않으며, 확인되지 않은 원인을 전문적 통찰이라는 이름으로 만들어내지 않는다.
- 발행 요일별 3일 관측창을 사용한다.

| 발행일 | 스페셜 관측창 | 해석 역할 |
|---|---|---|
| 월요일 | 토요일·일요일·월요일 | 주말 변동과 새 주 시작의 연결 |
| 수요일 | 월요일·화요일·수요일 | 주 초반 형성과 중간 점검 |
| 금요일 | 수요일·목요일·금요일 | 주 후반 변화와 주간 마감 전 점검 |

- 3일 자료는 각 날짜의 실제 관측값과 근거 상태가 있을 때만 사용한다. 누락일을 0으로 바꾸거나 추정하지 않는다.
- 3일치 일별 비교와 별도로 해당 기간의 통합 표·통합 다이어그램·종합 해석을 제공한다.
- 주간 대표지수, 전주 지수, 누적 성과는 각 지표의 정식 산식과 기간을 유지하며 3일치를 임의 합산해 대체하지 않는다.

#### 3.3.1 동일 분야 이전 2주 PUBLICITY 연계

- 스페셜 브리핑은 기준일 이전 2주 동안 공개된 동일 분야 PUBLICITY 자료를 포함한다. 기간 경계는 공개일을 기준으로 계산하고, 미래 예약기사·다른 분야 기사·비공개 초안은 포함하지 않는다.
- CPR 분석은 CPR, GOV 분석은 GOV, UNI 분석은 UNI, ENT 분석은 ENT 기사만 연결한다. 분야를 교차 혼합하지 않는다.
- 원문 기사 제목, 발행 회차, 기준일과 핵심 본문을 식별 가능하게 제시하고 원문의 의미를 바꾸거나 기존 공개 본문을 덮어쓰지 않는다.
- 선택 대상이 해당 2주 PUBLICITY의 헤드라인 대상이 아니어도 분야 기사 전체를 맥락 자료로 제공할 수 있다. 이때 각 기사 아래에 `선택 대상은 해당 주차에 어떤 특징이 있었는가?`라는 별도 소제목을 둔다.
- 선택 대상 추가 해설은 5~7개의 완결된 문장으로 작성한다. 해당 주차의 실제 공개 스냅샷과 근거 원장으로 확인된 내용만 사용하며 기사 헤드라인 대상의 특징을 선택 대상에게 전이하지 않는다.
- 예를 들어 GOV에서 교육부를 선택하고 해당 주차 기사 제목이 남양주시 1위 기사라면, 남양주시 기사 원문을 분야 맥락으로 먼저 제시한 뒤 교육부의 같은 주차 위치·6축·활동·근거 상태를 5~7문장으로 별도 설명한다.
- 2주 동안 해당 분야의 공개 PUBLICITY가 없거나 선택 대상의 적격 스냅샷이 없으면 없는 사실을 밝히고 생성하지 않는다. 다른 날짜나 기사를 추정해 채우지 않는다.

## 4. 사용자 선택과 비교 대상 적격성

1. 사용자는 먼저 분야 CPR·GOV·UNI·ENT 중 하나를 선택한다.
2. 기본 브리핑은 해당 분야 T100에서 중심 대상 1개를 선택한다.
3. 일반·스페셜 브리핑은 중심 대상 선택 후 같은 분야·같은 기준일 T100에서 비교 대상 2개를 추가 선택한다.
4. 비교 대상은 사용자 선택을 원칙으로 한다. 시스템이 임의로 경쟁 관계를 확정하지 않는다.
5. 선택 대상이 기준일 T100에 없거나 공개 적격 조건을 충족하지 않으면 결과를 억지로 생성하지 않고 선택 불가 사유를 안내한다.
6. 세 대상의 범위나 방법론 버전이 다르면 수치 비교를 중단하고 비교 가능 상태를 먼저 복원한다.
7. 사용자가 선택한 두 비교 대상의 분석적 관계를 보고서 첫 부분에 설명한다. 동일 업종·직군이라는 이유만으로 직접 경쟁자로 단정하지 않는다.

## 5. 분야별 적용 원칙

공통 문서 구조와 표 형식은 네 분야가 공유한다. 해석 문장은 분야별 2차 보완층을 반영한다.

| 분야 | 관계 해석의 중심 | 주의할 확대 해석 |
|---|---|---|
| CPR | 고객·시장·이해관계자와 기업의 관계 | 기업가치·투자등급·재무전망으로 확대하지 않음 |
| GOV | 시민·이용자·정책 공중과 기관의 관계 | 정책 성과·행정능력 전체의 판정으로 확대하지 않음 |
| UNI | 학생·학부모·구성원·사회와 대학의 관계 | 교육·연구 역량 전체 순위로 확대하지 않음 |
| ENT | 팬·일반 공중과 인물·콘텐츠의 관계 | 인기투표·실력·인격·팬덤 승패로 확대하지 않음 |

분야명은 `UNI`로 통일한다. 문서와 코드에서 `UIN` 표기를 사용하지 않는다.

## 6. 공통 서사 구조

### 6.1 이해

- BRIDGE의 공식 정의와 보고서의 중심 명제를 제시한다.
- 점수, 순위, 활동량, 신뢰등급, 관측·유지·참조의 차이를 설명한다.
- 독자가 뒤의 결과를 읽는 데 필요한 용어만 남기고 중복 정의는 피한다.

### 6.2 비교

- 기존 온라인 지수와 BRIDGE가 묻는 질문의 차이를 설명한다.
- 기존 지수를 틀렸다고 표현하지 않는다. 대상군·기간·개념·산출 목적의 차이를 밝힌다.
- 일반·스페셜에서는 세 대상을 선택한 이유와 비교 가능 조건을 함께 밝힌다.

### 6.3 순위 해석

- 순위는 해당 날짜와 대상군에서의 상대적 관계 위치임을 명시한다.
- 순위 상승과 점수 상승을 동일시하지 않는다.
- 점수 차이와 근거 신뢰도를 함께 제시한다.

### 6.4 실제 분석

- 중심 대상은 6축 전체, 종합지표, 변화, 활동량, 근거 상태를 분석한다.
- 비교 대상은 각자의 강한 축과 낮은 축을 함께 설명한다.
- 중심 대상의 강점뿐 아니라 유지 조건과 보완 과제를 제시한다.
- 다음 회차에서 검증할 질문을 남긴다.

### 6.5 대외 발표

- 앞의 분석에서 확인된 사실만 사용해 퍼블리시티를 작성한다.
- 제목에는 관심 장치와 해석 포인트를 함께 둔다.
- 순위나 1위 표현을 사용할 수 있으나 본문에서 기준일·대상군·관계 구조와 한계를 반드시 설명한다.
- 퍼블리시티는 보고서의 요약이 아니라 검증된 분석을 대중 언어로 재구성한 독립 결과물이다.

## 7. 일반 브리핑 페이지 시스템

일반 브리핑은 최소 21페이지를 계약 기준으로 삼고, 2026년 10월 25일 현재 운영 기준본은 다음 23페이지 구조다. 21페이지보다 줄일 수 없으며, 실제 사건·근거·비교 설명과 시각자료가 늘어나면 필요한 만큼 페이지를 추가한다. 장의 순서는 바꾸지 않는다.

각 페이지의 설명 본문은 원칙적으로 7~10개의 완결된 분석 문장으로 구성한다. 특히 11~21페이지는 이 범위를 권장이 아닌 제작·발행 계약으로 검사한다. 표·그림·수치·제목·주석과 표를 그대로 읽어 주는 문장은 이 문장 수에 포함하지 않는다. 문장 수를 채우기 위한 반복은 금지하며, 각 문장은 `사실·비교(장점·단점, 긍정·부정, 핵심 포인트)·의미(의의)·한계(한계 극복 조건 및 솔루션)·검증 질문·실무적 시사점(추론 전략화 및 실무 솔루션)` 중 하나의 내부 역할 태그를 가져야 한다. 11~21페이지의 각 페이지에는 최소 네 종류의 역할이 포함되어야 한다. 사실·비교 문장은 근거 원장의 공개 키와 연결되어야 한다. 역할 태그는 편집·감사용이며 외부 보고서 본문에는 노출하지 않는다. 퍼블리시티 페이지는 기사 완결성을 유지하면서도 충분한 분석 단위를 갖추고, 앞선 분석에서 확인되지 않은 내용을 추가하지 않는다.

근거가 부족한 경우 원인을 추정해 분량을 채우지 않는다. 그러나 설명을 짧게 끝내는 사유로도 사용하지 않는다. `무엇이 확인되지 않았는가`를 밝힌 뒤 현재 자료가 허용하는 의미를 최소 두 문장으로 설명한다. `어떤 데이터가 필요한가`를 밝힌 뒤 그 데이터가 확보될 때 가능해지는 판단을 최소 두 문장으로 설명한다. `다음 회차에서 무엇을 검증할 것인가`를 밝힌 뒤 실무적 시사점과 대응 솔루션을 최소 두 문장으로 설명한다. 그 밖에는 비교조건, 근거 지도 또는 명확히 조건을 붙인 시나리오 분석으로 보완한다. 사실성 규칙은 분량 규칙보다 우선하지만, 사실성 범위 안에서 최소 21페이지와 문장 밀도 계약을 모두 충족해야 한다. 둘 중 하나라도 충족하지 못하면 축약 발행하지 않고 발행을 보류한다.

### 7.1 비축약 원칙

1. 일반 브리핑은 최소 21페이지이며, 21페이지 미만 결과물은 완성본으로 취급하지 않는다.
2. 11~21페이지는 페이지당 7~10개의 완결된 분석문장을 반드시 갖춘다.
3. 표와 차트가 있어도 독자가 표를 읽지 않고 핵심 사실, 비교, 의미, 한계와 실무 대응을 이해할 수 있도록 문장으로 해설한다.
4. 표의 값을 순서대로 되읽는 문장은 분석문장에 포함하지 않는다. 수치의 관계와 해석 범위가 추가되어야 한다.
5. 자료 부족과 사실성 우선은 축약의 근거가 아니다. 확인 불가 사항, 필요한 데이터, 조건부 의미, 다음 검증과 실무 솔루션으로 설명량을 확보한다.
6. 동일 사실의 반복, 확인되지 않은 원인, 근거 없는 긍정·부정 추정으로 분량을 채우는 것은 금지한다.

## 8. 페이지 연결 규칙

- 각 페이지는 앞 페이지의 질문에 답하고 다음 페이지의 질문을 남긴다.
- 장 시작 페이지에는 한 문장의 결론을 먼저 둔다.
- 페이지 마지막 문장은 다음 페이지의 분석 이유를 자연스럽게 예고한다.
- 정의 페이지 다음에 바로 평가 결론을 두지 않는다. 독립축·종합지표·비교 가능성 설명을 거친다.
- 수치를 처음 제시하는 페이지에는 기준일, 분야, 대상군을 함께 표기한다.
- 같은 수치를 반복할 때는 새로운 해석이 있을 때만 재사용한다.
- 표가 다음 페이지로 분리되면 머리글을 반복하고 표의 목적을 다시 한 문장으로 알린다.
- 핵심 이슈는 한 페이지에 하나만 둔다. 서로 다른 쟁점을 한 표나 한 문단에 억지로 결합하지 않는다.

## 9. 글쓰기 규칙

### 9.1 제목

- 제목에는 관심 장치와 해석 포인트를 함께 넣는다.
- `대상명 + 핵심 수치 또는 위치 + 해석 과제`를 기본 구조로 사용한다.
- 과장된 승패·압도·추락 표현은 점수 차이와 근거가 뒷받침할 때도 신중하게 제한한다.

### 9.2 중심 명제

- 보고서 전체를 한 문장으로 설명할 중심 명제를 반드시 둔다.
- 강한 축, 낮은 축, 현재 의미와 다음 검증 과제를 한 문장 안에서 연결한다.

### 9.3 분석 문장

- 사실 → 해석 → 제한 → 다음 질문 순으로 쓴다.
- 수치를 제시한 뒤 의미를 설명하며, 수치 없는 형용사 평가를 피한다.
- 강한 축과 낮은 축을 함께 설명한다.
- `낮다`와 `나쁘다`, `높다`와 `긍정적이다`, `활발하다`와 `신뢰받는다`를 혼용하지 않는다.
- 인과가 검증되지 않으면 `이끌었다` 대신 `함께 관측됐다`, `기여한 구조로 해석된다`처럼 범위를 제한한다.
- 중심 대상의 긍정 요소를 충분히 설명하되 개선 과제를 숨기지 않는다.

### 9.4 비교 문장

- `누가 더 우수하다`보다 `어떤 관계 구조가 더 강하게 관측됐다`고 표현한다.
- 비교 대상의 독립적인 강점을 반드시 한 가지 이상 설명한다.
- 사용자가 선택한 중심 대상을 돋보이게 하기 위해 상대의 약점만 나열하지 않는다.
- 근소한 점수 차이를 압도적 우위로 표현하지 않는다.

## 10. 표와 시각자료 배치 규칙

- 표는 새로운 수치 집합을 처음 설명하는 문단 직후에 배치한다.
- 표 위에는 표가 답하는 질문을 한 문장으로 제시하고, 표 아래에는 가장 중요한 해석 한 문장을 둔다.
- 한 표는 한 가지 비교 목적만 가진다.
- 수치 비교표에는 기준일과 단위를 명시한다.
- 축 표는 항상 B·R·I·D·G·E 순서를 유지한다.
- 비교표의 대상 순서는 중심 대상, 비교 대상 A, 비교 대상 B로 고정한다.
- 참조축은 실제값처럼 선이나 막대로 연결하지 않는다. `참조·산출 제외`로 표시한다.
- 그림과 다이어그램은 본문에 이미 설명된 사실을 장식하지 않고, 관계·변화·시간 흐름을 더 쉽게 이해시킬 때만 사용한다.
- 일반 브리핑은 필수표 중심, 스페셜 브리핑은 3일 변화선·축 프로필·사건 흐름·통합 비교도까지 확장한다.

## 11. 페이지별 이슈 강조 규칙

- 장 제목은 네이비, 핵심 숫자와 방향 변화는 골드로 표시한다.
- 중심 대상은 골드, 비교 대상 A는 블루 그레이, 비교 대상 B는 로즈 그레이를 사용한다.
- 경고색은 오류·해석 보류·비교 불가에만 사용하고 낮은 점수에 자동 적용하지 않는다.
- 한 페이지의 강조 요소는 핵심 숫자 1~3개 또는 핵심 문장 1개로 제한한다.
- 신뢰등급은 `근거 신뢰등급 D · 평판등급이 아님`처럼 항상 의미를 병기한다.
- N/R은 `0점`이나 `불안정`이 아니라 산출 이력 부족임을 첫 등장 시 설명한다.

## 12. PDF와 화면 디자인 규칙

- 흰색을 기본 바탕으로 하고 따뜻한 미색은 표와 보조 구획에만 사용한다.

## 13.1 PUBLICITY 8블록 계약

PUBLICITY는 다음 여덟 블록을 내부 편집 구조로 사용한다. 화면에서 반드시 여덟 개의 제목으로 나눌 필요는 없지만 생성기와 감사기는 각 기능의 존재를 확인한다.

1. 관심 장치가 있는 헤드라인
2. 기준일·대상군·수치가 명확한 사실 리드
3. 순위 뒤의 관계 구조
4. 본인 변화·타 대상 변화·범위 효과를 구분한 변화 원인
5. 산출축·관측·유지·참조와 비교집합을 설명하는 근거 범위
6. CPR·GOV·UNI·ENT 분야별 관계 맥락
7. 인과·예측·절대 가치로 확대하지 않는 해석 한계
8. 다음 회차에서 확인할 수치·상태 기반 체크포인트

각 블록은 이름만 선언해서는 안 되며 실제 기사 문장과 연결되어야 한다. 생성기와 감사기는 여덟 블록의 본문 연결 여부와 전체 설명 밀도를 함께 검사한다. 2026년 10월 21일 공개된 `2026-w43-wed-ent`, `2026-w43-wed-uni`, `2026-w43-wed-cpr`의 전개를 편집 기준 사례로 삼아 `관심 장치 → 기준 사실 → 관계 구조 → 변화와 범위 → 분야 맥락 → 해석 한계 → 다음 질문`의 흐름을 유지한다. 기준 사례의 문장을 복제하지 않으며, 해당 회차의 검증된 데이터로 같은 편집 기능을 수행한다.

기존 공개 기사는 이 규칙을 이유로 자동 덮어쓰지 않는다. 새 규칙은 미래 회차와 명시적으로 승인된 정정본에만 적용한다.
