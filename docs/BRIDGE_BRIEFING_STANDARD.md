# BRIDGE 브리핑 제작 표준

## 상품 단계

- 기본 브리핑은 선택 대상의 핵심 지표와 6축 상태, 비교 대상의 요약, 짧은 비교 해설과 퍼블리시티를 제공한다.
- 일반 브리핑은 선택 대상의 전체 분석, 비교 대상 2개의 기본 브리핑, 3대상 구조 비교, 선택 대상의 유지 강점과 보완 과제, 독립 퍼블리시티 1편을 제공한다.
- 스페셜 브리핑은 일반 브리핑에 사건별 근거 흐름, 전일·전주·누적 변화, 축별 변화 원인, 추가 표·그림·다이어그램과 전략 시나리오를 확장한다.

## 선택 대상과 비교 대상

선택 대상은 분석 분량과 전략 해석에서 우선한다. 점수, 축 상태, 신뢰등급, 비교 기준은 모든 대상에게 동일하게 적용한다. 선택 대상을 돋보이게 하기 위해 비교축을 임의로 고르거나 다른 대상을 낮추지 않는다.

비교는 동일 날짜, 동일 분야, 동일 공개 범위에서 수행한다. 관측·유지 상태만 수치 비교에 사용하며 참조축은 제외한다. 비교 가능한 근거가 부족하면 차이를 억지로 산출하지 않는다.

## 일반 브리핑 순서

1. 표지와 보고서 식별정보
2. BRIDGE 브랜드평판지수와 6축 설명
3. 선택 대상 핵심 요약
4. 선택 대상 전체 분석
5. 비교 대상 A 기본 브리핑
6. 비교 대상 B 기본 브리핑
7. 세 대상의 종합 위치와 6축 비교
8. 가장 큰 차이와 관계 유형
9. 선택 대상의 유지 강점과 다음 관측 과제
10. 전체 결과를 아우르는 퍼블리시티 1편
11. 범위·신뢰등급·해석 제한과 방법론 주석

## 비교 표현 금지사항

1. 사용자의 클릭으로 점수를 올리는 응원 기능
2. 팬덤 간 대결과 승패를 강조하는 표현
3. 유리한 결과가 나올 때까지 반복 실행하는 기능
4. 근거가 부족한 대상을 억지로 점수화하는 처리
5. 점수 구매 또는 유료 노출과 지수 산출의 결합
6. 공격적이거나 비하하는 비교 문구의 자동 생성

## 화면과 PDF의 역할

반응형 화면은 세 대상의 종합 위치, 6축 구조, 가장 큰 차이, 관계 유형을 빠르게 발견하는 인터페이스다. PDF는 전체 분석, 표·그림·다이어그램, 근거 상태, 해석 한계와 퍼블리시티를 보관·전달하는 정식 결과물이다. 하나의 정식 PDF를 제공하고 별도의 모바일 PDF는 만들지 않는다. 모바일 화면에는 `보고서 바로 보기`와 `PDF 저장하기`를 함께 제공한다.

## PDF 디자인 규칙

- 흰색을 기본 바탕으로 하고 따뜻한 미색은 표와 보조 구획에만 사용한다.
- 검은색 대신 딥 네이비를 기본 문자색으로 사용한다.
- 상단 왼쪽에는 작은 SIGNALBRIDGE 로고타입을 둔다.
- 상단 오른쪽에는 분야·브리핑 단계·기준일을 표기한다.
- 하단에는 페이지 번호와 보고서 식별번호를 표기한다.
- 장 제목은 네이비, 핵심 숫자와 변화는 골드로 표시한다.
- 표는 네이비 머리글과 흰색 본문을 사용한다.
- 비교 대상 식별색은 선택 대상 골드, 비교 대상 A 블루 그레이, 비교 대상 B 로즈 그레이로 고정한다.
- 큰 워터마크는 표지와 주요 장 시작 면에만 3~5% 농도로 사용하며 본문과 표 뒤에는 반복하지 않는다.
- A4 세로형, 본문 10.5~11포인트 이상을 유지하고 모바일에서 가로 회전이 필요한 표를 만들지 않는다.

## 해석 원칙

순위는 정해진 날짜와 대상군에서 관측된 상대적 관계 위치다. 대상의 절대적 가치·능력·윤리성 전체를 판정하지 않는다. 활동량과 평판 수준을 구분하고, 점수와 근거 신뢰등급을 분리해 설명한다. 선택 대상의 약한 축은 부정적 낙인 대신 현재 근거 범위에서의 보완 및 다음 관측 과제로 기술한다.
