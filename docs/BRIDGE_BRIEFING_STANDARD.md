# BRIDGE 브리핑 제작 시스템 표준

## 1. 목적과 적용 범위

이 문서는 BRIDGE 기본·일반·스페셜 브리핑의 목록, 구조, 분석 방식, 글쓰기, 페이지 구성, 표와 시각자료의 배치 및 검수 기준을 규정한다. ENT에서 확립한 형식을 CPR·GOV·UNI에도 동일하게 적용하되, 공통 6축과 근거 원칙은 유지하고 각 분야의 2차 보완층으로 해석만 조정한다.

모든 브리핑은 다음 다섯 단계로 전개한다.

> 이해 → 비교 → 순위 해석 → 실제 분석 → 대외 발표

이 흐름은 단순한 목차가 아니라 독자가 지표를 오해하지 않고 결과에 도달하도록 만드는 논증 순서다. 앞 단계에서 정의하지 않은 용어나 판단을 뒤 단계에서 갑자기 사용하지 않는다.

## 2. 공통 데이터 원칙

- 동일 보고서 안의 수치 비교는 동일 기준일, 동일 분야, 동일 방법론 버전, 동일 공개 범위에서 수행한다.
- 관측·유지 상태만 종합지수와 수치 비교에 사용하고 참조값은 제외한다.
- 순위, 점수, 활동량, 근거 신뢰등급을 서로 다른 개념으로 분리해 설명한다.
- 활동량을 긍정 평판으로 해석하지 않는다.
- 실제 점수 변화와 근거 범위 변화를 구분한다. 비교 범위가 달라지면 변화 해석을 보류한다.
- 낮은 축을 곧바로 부정·실패·도덕성 문제로 해석하지 않는다. 현재 근거 범위에서 상대적으로 약하게 관측된 관계와 부정적 사건을 구분한다.
- 내부 가중치, 비밀키, 임계값, 비공개 원장과 수집 전략은 외부 보고서에 노출하지 않는다.
- 기존 공개 기사를 덮어쓰거나 동일 회차를 중복 발행하지 않는다.

## 3. 브리핑 단계와 대상 선택 규칙

### 3.1 기본 브리핑

- 사용자가 선택한 분석 대상 1개만 다룬다.
- 비교 대상은 포함하지 않는다.
- 핵심 지표, 6축 상태, 강한 축과 낮은 축, 주요 변화, 활동량, 근거 범위, 다음 관측 질문을 설명한다.
- 선택 대상 1개에 관한 짧은 퍼블리시티 1편을 포함한다.

### 3.2 일반 브리핑

- 사용자가 선택한 중심 대상 1개와 사용자가 직접 선택한 비교 대상 2개를 다룬다.
- 세 대상은 같은 분야의 해당 기준일 T100 안에서만 선택한다.
- 중심 대상은 전체 분석을 제공하고, 비교 대상 2개는 기본 브리핑 수준으로 설명한다.
- 세 대상의 종합 위치, 6축 구조, 가장 큰 차이, 관계 유형, 활동량과 변화 방향을 비교한다.
- 중심 대상을 강조할 수 있으나 동일 기준을 적용하며, 비교 대상을 낮추거나 중심 대상에 유리한 축만 선별하지 않는다.
- 세 대상 전체를 아우르는 독립 퍼블리시티 1편을 포함한다.

### 3.3 스페셜 브리핑

- 일반 브리핑의 중심 대상 1개와 비교 대상 2개 구조를 기본으로 한다.
- 일반 브리핑의 모든 항목에 표·그림·다이어그램, 축별 변화 원인, 사건 흐름, 근거 상태 변화와 전문 해설을 추가한다.
- 발행 요일별 3일 관측창을 사용한다.

| 발행일 | 스페셜 관측창 | 해석 역할 |
|---|---|---|
| 월요일 | 토요일·일요일·월요일 | 주말 변동과 새 주 시작의 연결 |
| 수요일 | 월요일·화요일·수요일 | 주 초반 형성과 중간 점검 |
| 금요일 | 수요일·목요일·금요일 | 주 후반 변화와 주간 마감 전 점검 |

- 3일 자료는 각 날짜의 실제 관측값과 근거 상태가 있을 때만 사용한다. 누락일을 0으로 바꾸거나 추정하지 않는다.
- 3일치 일별 비교와 별도로 해당 기간의 통합 표·통합 다이어그램·종합 해석을 제공한다.
- 주간 대표지수, 전주 지수, 누적 성과는 각 지표의 정식 산식과 기간을 유지하며 3일치를 임의 합산해 대체하지 않는다.

## 4. 사용자 선택과 비교 대상 적격성

1. 사용자는 먼저 분야 CPR·GOV·UNI·ENT 중 하나를 선택한다.
2. 기본 브리핑은 해당 분야 T100에서 중심 대상 1개를 선택한다.
3. 일반·스페셜 브리핑은 중심 대상 선택 후 같은 분야·같은 기준일 T100에서 비교 대상 2개를 추가 선택한다.
4. 비교 대상은 사용자 선택을 원칙으로 한다. 시스템이 임의로 경쟁 관계를 확정하지 않는다.
5. 선택 대상이 기준일 T100에 없거나 공개 적격 조건을 충족하지 않으면 결과를 억지로 생성하지 않고 선택 불가 사유를 안내한다.
6. 세 대상의 범위나 방법론 버전이 다르면 수치 비교를 중단하고 비교 가능 상태를 먼저 복원한다.
7. 사용자가 선택한 두 비교 대상의 분석적 관계를 보고서 첫 부분에 설명한다. 동일 업종·직군이라는 이유만으로 직접 경쟁자로 단정하지 않는다.

## 5. 분야별 적용 원칙

공통 문서 구조와 표 형식은 네 분야가 공유한다. 해석 문장은 분야별 2차 보완층을 반영한다.

| 분야 | 관계 해석의 중심 | 주의할 확대 해석 |
|---|---|---|
| CPR | 고객·시장·이해관계자와 기업의 관계 | 기업가치·투자등급·재무전망으로 확대하지 않음 |
| GOV | 시민·이용자·정책 공중과 기관의 관계 | 정책 성과·행정능력 전체의 판정으로 확대하지 않음 |
| UNI | 학생·학부모·구성원·사회와 대학의 관계 | 교육·연구 역량 전체 순위로 확대하지 않음 |
| ENT | 팬·일반 공중과 인물·콘텐츠의 관계 | 인기투표·실력·인격·팬덤 승패로 확대하지 않음 |

분야명은 `UNI`로 통일한다. 문서와 코드에서 `UIN` 표기를 사용하지 않는다.

## 6. 공통 서사 구조

### 6.1 이해

- BRIDGE의 공식 정의와 보고서의 중심 명제를 제시한다.
- 점수, 순위, 활동량, 신뢰등급, 관측·유지·참조의 차이를 설명한다.
- 독자가 뒤의 결과를 읽는 데 필요한 용어만 남기고 중복 정의는 피한다.

### 6.2 비교

- 기존 온라인 지수와 BRIDGE가 묻는 질문의 차이를 설명한다.
- 기존 지수를 틀렸다고 표현하지 않는다. 대상군·기간·개념·산출 목적의 차이를 밝힌다.
- 일반·스페셜에서는 세 대상을 선택한 이유와 비교 가능 조건을 함께 밝힌다.

### 6.3 순위 해석

- 순위는 해당 날짜와 대상군에서의 상대적 관계 위치임을 명시한다.
- 순위 상승과 점수 상승을 동일시하지 않는다.
- 점수 차이와 근거 신뢰도를 함께 제시한다.

### 6.4 실제 분석

- 중심 대상은 6축 전체, 종합지표, 변화, 활동량, 근거 상태를 분석한다.
- 비교 대상은 각자의 강한 축과 낮은 축을 함께 설명한다.
- 중심 대상의 강점뿐 아니라 유지 조건과 보완 과제를 제시한다.
- 다음 회차에서 검증할 질문을 남긴다.

### 6.5 대외 발표

- 앞의 분석에서 확인된 사실만 사용해 퍼블리시티를 작성한다.
- 제목에는 관심 장치와 해석 포인트를 함께 둔다.
- 순위나 1위 표현을 사용할 수 있으나 본문에서 기준일·대상군·관계 구조와 한계를 반드시 설명한다.
- 퍼블리시티는 보고서의 요약이 아니라 검증된 분석을 대중 언어로 재구성한 독립 결과물이다.

## 7. 일반 브리핑 페이지 시스템

일반 브리핑은 다음 21페이지 구조를 최소 표준으로 삼는다. 21페이지보다 줄일 수 없으며, 실제 사건·근거·비교 설명과 시각자료가 늘어나면 필요한 만큼 페이지를 추가한다. 장의 순서는 바꾸지 않는다.

각 페이지의 설명 본문은 원칙적으로 7~10개의 완결된 분석 문장으로 구성한다. 표·그림·수치·제목·주석은 이 문장 수에 포함하지 않는다. 문장 수를 채우기 위한 반복은 금지하며, 각 문장은 사실, 의미, 해석 한계 또는 다음 검증 질문 중 하나의 독립적인 역할을 가져야 한다. 퍼블리시티 페이지는 고정 문장 수보다 기사 완결성과 해당 회차의 실제 분석량을 우선하되, 앞선 분석에서 확인되지 않은 내용을 추가하지 않는다.

| 페이지 | 장 | 핵심 내용 | 시각 요소 |
|---:|---|---|---|
| 1 | 표지 | 제목·대상·기준일·핵심 한 문장 | 최소 정보 표지 |
| 2 | 결론과 정의 | 중심 대상·비교 대상·BRIDGE 공식 정의 | 대상 선택 요약 |
| 3 | 지표 읽기 | 점수·신뢰등급·관측·유지·참조 | 3열 정의표 |
| 4 | 독립축 | BRIDGE 6축 개별 의미 | 6축 도식 또는 표 |
| 5 | 결합축 | 두 축 결합의 진단적 해석 | 15개 결합표 |
| 6 | 종합지표 | Daily·Weekly·WoW·Activity 등 | 지표 해석표 |
| 7 | 기존 지수 비교 | 질문·기간·점수 성격의 차이 | 비교표 |
| 8 | 차별점 | BRIDGE의 핵심 차별점 7개 | 번호형 요약 |
| 9 | 순위 차이 | 대상군·기간·측정 질문 차이 | 원인 목록 |
| 10 | 판단 기준 | 어느 지수가 어떤 질문에 적합한가 | 선택표 |
| 11 | 순위 해석 | 순위·점수·등락의 관계 | 실제 사례 |
| 12 | 목록 해석 | T100과 보조 관측군 | 역할 비교 |
| 13 | 분석 개요 | 제목·중심 명제·세 대상 위치 | 핵심 수치표 |
| 14 | 중심 대상 | 중심 대상 전체 분석 | 6축표 |
| 15 | 비교 대상 A | 기본 브리핑 | 6축표 |
| 16 | 비교 대상 B | 기본 브리핑 | 6축표 |
| 17 | 구조 비교 | 관계 유형·강점·과제 | 비교 매트릭스 |
| 18 | 변화 분석 | 활동량·실제 변화·근거 범위 | 변화표 |
| 19 | 종합 판단 | 중심 대상의 의미와 다음 질문 | 결론 목록 |
| 20 | 퍼블리시티 | 대외용 기사 | 기사형 본문 |
| 21 | 한계와 출처 | 해석 제한·방법론·참고자료 | 주석 목록 |

기본 브리핑은 위 원형에서 비교 대상과 세 대상 비교 페이지를 제거해 축약한다. 스페셜 브리핑은 13~19페이지 구간에 3일 관측창과 추가 시각자료를 확장한다.

## 8. 페이지 연결 규칙

- 각 페이지는 앞 페이지의 질문에 답하고 다음 페이지의 질문을 남긴다.
- 장 시작 페이지에는 한 문장의 결론을 먼저 둔다.
- 페이지 마지막 문장은 다음 페이지의 분석 이유를 자연스럽게 예고한다.
- 정의 페이지 다음에 바로 평가 결론을 두지 않는다. 독립축·종합지표·비교 가능성 설명을 거친다.
- 수치를 처음 제시하는 페이지에는 기준일, 분야, 대상군을 함께 표기한다.
- 같은 수치를 반복할 때는 새로운 해석이 있을 때만 재사용한다.
- 표가 다음 페이지로 분리되면 머리글을 반복하고 표의 목적을 다시 한 문장으로 알린다.
- 핵심 이슈는 한 페이지에 하나만 둔다. 서로 다른 쟁점을 한 표나 한 문단에 억지로 결합하지 않는다.

## 9. 글쓰기 규칙

### 9.1 제목

- 제목에는 관심 장치와 해석 포인트를 함께 넣는다.
- `대상명 + 핵심 수치 또는 위치 + 해석 과제`를 기본 구조로 사용한다.
- 과장된 승패·압도·추락 표현은 점수 차이와 근거가 뒷받침할 때도 신중하게 제한한다.

### 9.2 중심 명제

- 보고서 전체를 한 문장으로 설명할 중심 명제를 반드시 둔다.
- 강한 축, 낮은 축, 현재 의미와 다음 검증 과제를 한 문장 안에서 연결한다.

### 9.3 분석 문장

- 사실 → 해석 → 제한 → 다음 질문 순으로 쓴다.
- 수치를 제시한 뒤 의미를 설명하며, 수치 없는 형용사 평가를 피한다.
- 강한 축과 낮은 축을 함께 설명한다.
- `낮다`와 `나쁘다`, `높다`와 `긍정적이다`, `활발하다`와 `신뢰받는다`를 혼용하지 않는다.
- 인과가 검증되지 않으면 `이끌었다` 대신 `함께 관측됐다`, `기여한 구조로 해석된다`처럼 범위를 제한한다.
- 중심 대상의 긍정 요소를 충분히 설명하되 개선 과제를 숨기지 않는다.

### 9.4 비교 문장

- `누가 더 우수하다`보다 `어떤 관계 구조가 더 강하게 관측됐다`고 표현한다.
- 비교 대상의 독립적인 강점을 반드시 한 가지 이상 설명한다.
- 사용자가 선택한 중심 대상을 돋보이게 하기 위해 상대의 약점만 나열하지 않는다.
- 근소한 점수 차이를 압도적 우위로 표현하지 않는다.

## 10. 표와 시각자료 배치 규칙

- 표는 새로운 수치 집합을 처음 설명하는 문단 직후에 배치한다.
- 표 위에는 표가 답하는 질문을 한 문장으로 제시하고, 표 아래에는 가장 중요한 해석 한 문장을 둔다.
- 한 표는 한 가지 비교 목적만 가진다.
- 수치 비교표에는 기준일과 단위를 명시한다.
- 축 표는 항상 B·R·I·D·G·E 순서를 유지한다.
- 비교표의 대상 순서는 중심 대상, 비교 대상 A, 비교 대상 B로 고정한다.
- 참조축은 실제값처럼 선이나 막대로 연결하지 않는다. `참조·산출 제외`로 표시한다.
- 그림과 다이어그램은 본문에 이미 설명된 사실을 장식하지 않고, 관계·변화·시간 흐름을 더 쉽게 이해시킬 때만 사용한다.
- 일반 브리핑은 필수표 중심, 스페셜 브리핑은 3일 변화선·축 프로필·사건 흐름·통합 비교도까지 확장한다.

## 11. 페이지별 이슈 강조 규칙

- 장 제목은 네이비, 핵심 숫자와 방향 변화는 골드로 표시한다.
- 중심 대상은 골드, 비교 대상 A는 블루 그레이, 비교 대상 B는 로즈 그레이를 사용한다.
- 경고색은 오류·해석 보류·비교 불가에만 사용하고 낮은 점수에 자동 적용하지 않는다.
- 한 페이지의 강조 요소는 핵심 숫자 1~3개 또는 핵심 문장 1개로 제한한다.
- 신뢰등급은 `근거 신뢰등급 D · 평판등급이 아님`처럼 항상 의미를 병기한다.
- N/R은 `0점`이나 `불안정`이 아니라 산출 이력 부족임을 첫 등장 시 설명한다.

## 12. PDF와 화면 디자인 규칙

- 흰색을 기본 바탕으로 하고 따뜻한 미색은 표와 보조 구획에만 사용한다.
- 검은색 대신 딥 네이비를 기본 문자색으로 사용한다.
- 상단 왼쪽에는 작은 SIGNALBRIDGE 로고타입을 둔다.
- 상단 오른쪽에는 분야·브리핑 단계·기준일을 표기한다.
- 하단에는 페이지 번호와 보고서 식별번호를 표기한다.
- 표는 네이비 머리글과 흰색 본문을 사용한다.
- 큰 워터마크는 표지와 주요 장 시작 면에만 3~5% 농도로 사용한다.
- A4 세로형, 본문 10.5~11포인트 이상을 유지하고 모바일에서 가로 회전이 필요한 표를 만들지 않는다.
- 반응형 화면은 핵심 위치와 차이를 발견하게 하고, PDF는 전체 분석과 근거·한계·퍼블리시티를 보관하는 정식 결과물로 사용한다.

## 13. 제작 전 검수 질문

1. 제목에 관심 장치와 해석 포인트가 함께 있는가?
2. 한 문장으로 설명할 중심 명제가 있는가?
3. 순위와 점수의 기준일·분야·대상군이 명확한가?
4. 가장 강한 축과 낮은 축을 함께 설명했는가?
5. 실제 변화와 근거 범위 변화를 구분했는가?
6. 활동량을 긍정 평판으로 오해하지 않았는가?
7. 비교 대상 2개는 사용자가 같은 분야 T100에서 선택했는가?
8. 비교 대상 선정과 비교 가능성의 이유를 설명했는가?
9. 참조값을 실제 평가값처럼 해석하지 않았는가?
10. 해당 분야의 2차 관계 특성이 문장에 반영됐는가?
11. 중심 대상과 비교 대상 모두에게 동일한 산출 기준을 적용했는가?
12. 다음 회차에서 검증할 질문을 남겼는가?
13. 표가 본문의 질문에 답하고 다음 해석으로 연결되는가?
14. 퍼블리시티가 앞의 분석에서 확인된 사실만 사용하는가?
15. 내부 가중치·임계값·비공개 근거가 노출되지 않았는가?

하나라도 충족하지 못하면 최종 브리핑으로 확정하지 않는다.

## 14. 금지사항

1. 사용자의 클릭으로 점수를 올리는 응원 기능
2. 팬덤·기업·기관·대학 간 대결과 승패를 강조하는 표현
3. 유리한 결과가 나올 때까지 반복 실행하는 기능
4. 근거가 부족한 대상을 억지로 점수화하는 처리
5. 점수 구매 또는 유료 노출과 지수 산출의 결합
6. 공격적이거나 비하하는 비교 문구의 자동 생성
7. 비교 대상에 서로 다른 날짜·방법론·공개 범위를 혼합하는 처리
8. 3일 관측창의 누락 자료를 추정하거나 0으로 채우는 처리

## 15. 현재 확정 범위와 추후 논의사항

현재 확정된 사항은 다음과 같다.

- 기본은 중심 대상 1개 단독 분석이다.
- 일반은 중심 대상 1개와 사용자 지정 비교 대상 2개의 비교 분석이다.
- 스페셜은 일반 구조에 요일별 3일 자료와 추가 시각·통합 분석을 더한다.
- 네 분야는 동일한 제작 시스템을 사용하고 분야별 2차 보완층으로 해석한다.

일반 브리핑은 최소 21페이지, 각 페이지 설명 본문은 원칙적으로 7~10문장으로 확정한다. 기본 브리핑은 비교 분석을 제거한 축약형으로 별도 최소 분량을 정하고, 스페셜 브리핑은 일반형보다 많은 시각자료와 요일별 3일 관측창을 포함해 21페이지 이상으로 확장한다. 퍼블리시티 길이, 상품별 제공 빈도와 가격은 실제 데이터량과 상품 설계에 따라 별도 확정한다.
