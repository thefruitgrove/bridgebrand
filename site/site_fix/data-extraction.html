출처·기준시점·대상 귀속·중복·유효기간을 확인하고, 실제 변화와 근거 범위의 변화를 구분합니다.

01 / SOURCES

빠른 신호와 오래 유지되는 기반

뉴스·공식 채널·공중 반응은 비교적 빠른 변화를, 공시·교육여건·공식 통계와 평가자료는 기준기간의 기반을 설명합니다. 이들은 같은 종류의 근거가 아닙니다. 자료 유형별 활용 범위가 다르고, 모든 대상에서 모든 출처가 확보되는 것은 아닙니다. 공식 홍보 문구도 공중의 긍정 반응으로 곧바로 바꾸어 읽지 않습니다.

  1. 자료출처와 기준시점 확인
  2. 대상·사건귀속과 중복 점검
  3. 축·기간평가 목적과 유효성 확인
  4. 공개 결과지수·근거 상태·해석
02 / VALIDITY

오래된 사건을 새 사건으로 만들지 않습니다

발생·발행 시점과 수집 시점, 자료의 기준기간을 구분합니다. 유효성은 영역·축·자료 유형에 맞춘 공통 규칙으로 관리하는 것이 원칙입니다. 유효한 공시가 다음 날에도 평가 기반이 될 수는 있지만 매일 새로운 활동으로 반복 가산되지는 않습니다. 책임 사건은 기간 경과만으로 후속 조치와 이력이 사라졌다고 해석하지 않습니다.

03 / DISTINCT EVENTS

사건의 수와 확산의 크기를 구분합니다

동일 자료의 재수집과 전재를 독립 사건처럼 반복 세지 않습니다. 실질적으로 새로운 사실이나 반응이 있는 후속 자료는 구분해 검토합니다. 한 사건이 여러 축을 설명하더라도 활동량은 사건 단위로 관리합니다. 영상의 누적 반응과 관측 시점 사이의 증분도 구별해야 합니다.

04 / OBSERVATION

발견하지 못한 것과 관측하지 못한 것은 다릅니다

정해진 수집 범위를 정상적으로 확인했으나 유효 언급을 찾지 못한 경우와, 실패·차단·실행 누락으로 확인하지 못한 경우를 구분합니다. 부분 관측은 확보된 근거만 해석하며 전체 무언급으로 확장하지 않습니다. 수집 실패를 대상의 소통 부재나 부정적 평판으로 바꾸지 않습니다.

05 / COVERAGE

일주일의 두께를 함께 읽습니다

수집이 정상 완료된 날과 새로운 근거가 발견된 날은 서로 다른 정보입니다. 유효 축의 범위, 자료의 최신성, 출처 구성, 기존 기준자료에 대한 의존도도 함께 살펴야 합니다. 하루의 자료가 있는 잠정 주간값을 일주일 전체를 관측한 결과처럼 표현하지 않습니다.

06 / COMPARABILITY

평판의 변화와 근거 범위의 변화를 나눠 봅니다

새로운 축·출처가 추가되거나 기존 근거가 만료되면 비교 조건이 달라집니다. 기준 변경과 근거 범위 확대·축소는 해석에 함께 표시해야 합니다. 공통 축이 있더라도 출처 구성까지 같다는 보장은 없으므로 점수 차이를 순수한 인과 효과로 설명하지 않습니다. 신뢰등급은 이 판단을 돕는 근거 충실성 정보입니다.
